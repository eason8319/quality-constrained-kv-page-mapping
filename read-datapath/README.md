# Attention Read Datapaths for Low-Bit KV Cache Pages

课题二：面向低比特 KV 页的注意力读通路

本文件展开本课题的研究内容；共同约束与跨课题接口以总研究规划为准。调整本课题范围时，应同步更新总文档对应章节。

## 1. 核心问题

在给定质量和性能约束下，何时应先反量化再乘加，何时可以利用低比特表示进行部分累加后处理尺度？共享通路能否在支持配置选择的同时获得净收益？

## 2. 必须前移的算术判定

首轮计划用一至两周完成 A/B 算术形式、操作计数和小规模数值验证；这是可行性检查窗口，不以时间到期代替正确性验收。

- **模式 A：** 将 KV 反量化到规定的计算精度，再执行乘加。
- **模式 B：** 在已证明可行的范围内进行低比特乘加或部分累加，再完成尺度和零点处理。具体形式可为分组部分和、将尺度作用移到另一操作数，或其他经验证的等价组织。
- **模式 C：** 低比特主流加可恢复精度的残差，暂不作为核心必须支持的模式。只有在线升档扩展通过判定后再定义。

对 QK^T 和 PV 分别写明尺度在什么维度变化、能否移出求和、零点修正如何计算、Q/P 是否需要量化，以及乘积和累加位宽。若引入 Q/P 量化，其质量影响进入共同黄金模型。

K 按通道、V 按 token 的尺度通常随对应归约维度变化，不能默认整页求和后只乘一次尺度。若 B 只能在更宽尺度共享条件下成立，则将问题明确改为“何时值得放宽分组以支持低比特域累加”，并请求课题一补充该配置的质量验证。

## 3. 研究内容

1. A/B 在 QK^T 与 PV 上的面积、关键路径、吞吐和能量模型及实现。
2. 包含数据、尺度、零点、描述符、缓冲与实际访存的成本比较。
3. 可重构单元的资源共享、控制和配置切换；记录切换方向、周期、流水线气泡和能量。
4. 在相同质量和性能约束下，与最佳单模式实现及合理的独立通路组合比较，形成配置与通路的适用规则。
5. 与 W 共同定义未满页读取、尺度版本切换和页关闭流程。若 W 合并，扩展为共享数据表示下的读写通路设计。

## 4. 贡献边界

本课题负责“如何计算、代价是什么、哪些配置适合哪些通路”。不决定每一页最终配置，不重复课题一的敏感度发现，不负责课题三的质量预算分配。

softmax 的内部结构不作为研究贡献，但其精度与接口必须固定；能量统计中采用统一处理，不能无说明地忽略必要开销。

## 5. 成文判定与退路

需要证明尺度组织与配置会改变优选通路，并在同质量、同吞吐或明确性能约束下获得可计量的净收益。共享电路小于两套独立电路的面积之和，只是基础结果，不单独构成充分贡献。

如果 B 没有有效适用区间，应如实收缩模式集合。只有负面的 A/B 对比时，需重新评估独立成文；可结合 W 形成有共同数据表示与硬件复用机制的读写通路论文，不能仅靠拼接模块增加篇幅。

## 6. 交付物

经验证的算术定义、合法的配置—模式组合、读通路 RTL、包含条件参数的代价模型、模式切换模型及未满页读取接口。

## 并行开展与交接

可与课题一、W 并行开展 A/B 算术推导和参数化原型；最终 RTL 使用共同冻结的接口。

- 从课题一取得配置与质量约束；改变尺度共享范围时，回传课题一补做质量验证。
- 与课题 W 共同确定未满页读取、尺度版本、读写冲突和关闭页提交协议。
- 向课题三提供合法配置与模式组合、完整计算成本和切换成本。
- 若 W 不独立成文，本课题承接其写通路功能与交付物。

## 共同约束与接口

- 比特档为 2、4、8；以 K 按通道、V 按 token 的非对称均匀量化为共同基准，不以训练、微调或新量化公式为贡献。
- 页长在一次实验或实现内固定。配置必须能被页格式表达、由保留数据生成，并由实际通路执行。
- 使用共同的全精度质量参照、校准与测试划分、比特精确模型、硬件预算及完整成本口径。
- 初期保持参数化；最终实现与正式评估前共同冻结尺度语义、页生命周期、描述符、配置集合和成本接口。
- 模型、任务、质量预算和具体硬件参数尚待共同确定；本文描述研究目标，不表示已取得实验结果。
