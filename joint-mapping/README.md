# Quality-Constrained Joint Configuration Mapping at KV Page Closure

课题三：页关闭时的质量约束联合映射

[返回总研究规划](../质量约束下低比特KV页联合映射-论文课题.md)

本文件展开本课题的研究内容；共同约束与跨课题接口以总研究规划为准。调整本课题范围时，应同步更新总文档对应章节。

## 1. 核心问题

页关闭时，利用决策时可获得的信息，在真实可生成且可执行的候选配置中联合选择比特档、组大小和通路模式，在给定质量及性能约束下降低能量。

这里的“静态”表示关闭后配置固定，不表示所有页统一配置，也不表示整个策略只能离线运行。在线策略依赖统计代理；任务得分是离线验证依据，不作为推理时天然可观测的报警信号。

## 2. 前置输入

- 课题一提供质量特征、有效统计或粗粒度先验、配置验证状态和离线参照。
- 课题二提供合法模式、运算成本、切换成本和实际性能约束。
- W 或并入课题二的写通路提供可用统计、保留的数据、可生成配置和关闭页成本。

W 是否独立发表不改变这项功能依赖。

## 3. 研究内容

1. 将质量代理、候选配置和硬件成本结合，建立页关闭时的决策方法。
2. 约束可选配置为“质量验证允许、暂存数据可生成、读通路可执行”的交集，不把软件能表示的全部配置当作在线可选项。
3. 计入统计提取、决策、描述符访问、暂存、最终量化或重编码、数据搬移、模式切换和后续读取成本。
4. 固定或明确建模页处理顺序及切换状态。若估计未来读取次数或摊销写入成本，说明估计来源并评估偏差，不能使用不可获得的未来信息。
5. 在独立测试集上验证任务质量约束，报告预算违规、性能约束不满足的情形及处理方式。

## 4. 对照与消融

- 全精度质量参照，以及统一 4 比特、统一 8 比特等固定配置；不满足预算的结果标记为不可行，不能当作同质量胜负比较。
- KIVI、QServe、KVTuner 等相关方法，以及与最终机制直接相关的更新工作。保持原方法关键特性，或明确将统一格式上的版本标为移植版并说明修改。
- 只选比特、比特加组大小、比特加组大小加模式；同时比较联合选择与分步选择。
- 仅用层/头/位置的策略、使用额外统计的策略，以及离线敏感度参照。
- 小规模问题上，比较筛选前后配置空间的可验证最优解或明确标注的离线搜索结果。若求解只优化代理目标，不能称为真实任务质量下的全局最优。
- 驱逐方法可作为外部参照，核心结论仍围绕完整 KV 内容上的精度与通路配置。

## 5. 贡献边界与成文判定

课题一研究“是否存在可利用信息”，课题三研究“如何把这些信息转化为考虑完整成本的可执行决策”。课题三不能只重复课题一的预测器与混合分配实验。

独立成文需要证明联合选择的必要性、策略在所声明质量与性能约束下的可行性，以及相对有竞争力基线的净收益。若额外统计或联合变量没有收益，应收缩结论，不预设一定优于所有对照。

若逐页预测不可靠，可退回按层或按头的映射，但仍须验证组大小、通路和完整硬件成本联合决策的额外贡献。粗粒度回退不自动保证独立论文；贡献不足时可与课题一或系统实现合并。

## 并行开展与交接

前期可同步定义目标、接口、对照和简单参照策略；正式策略与收益评估等待课题一的有效质量信息和课题二、W 的完整成本输入。

- 从课题一取得质量规律、预测能力、配置验证状态与离线参照。
- 从课题二取得合法模式、性能约束与切换成本。
- 从 W 或并入课题二的写通路取得保留数据、可用统计、可生成配置与最终转换成本。
- 决策范围是质量验证允许、暂存可生成、读通路可执行三者的交集。
- 核心在页关闭后固定配置；在线升档需要新增触发与残差接口，只作为后续扩展。

## 共同约束与接口

- 比特档为 2、4、8；以 K 按通道、V 按 token 的非对称均匀量化为共同基准，不以训练、微调或新量化公式为贡献。
- 页长在一次实验或实现内固定。配置必须能被页格式表达、由保留数据生成，并由实际通路执行。
- 使用共同的全精度质量参照、校准与测试划分、比特精确模型、硬件预算及完整成本口径。
- 初期保持参数化；最终实现与正式评估前共同冻结尺度语义、页生命周期、描述符、配置集合和成本接口。
- 模型、任务、质量预算和具体硬件参数尚待共同确定；本文描述研究目标，不表示已取得实验结果。

完整约束、页关闭契约、描述符定义、并行阶段与相关工作见[总研究规划](../质量约束下低比特KV页联合映射-论文课题.md)。
