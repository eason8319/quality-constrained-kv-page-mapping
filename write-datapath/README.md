# Online Scale Determination and Write Datapaths for KV Cache Pages

课题 W：在线尺度确定与 KV 页写通路

本文件展开本课题的研究内容；共同约束与跨课题接口以总研究规划为准。调整本课题范围时，应同步更新总文档对应章节。

## 1. 核心问题

采用整页数据决定最终量化范围时，K 的最终尺度需等相关数据到齐。如何在暂存容量、尺度表示、重编码误差和写流量之间取舍，并保证未满页可被读取、关闭页可生成最终格式？

研究重点是尺度确定时机、尺度表示和原地重编码。页统计电路为附带内容；其选择依赖课题一，不能反过来阻塞 W 的核心验证。

## 2. 独立成文的早期判定

**第一关：资源压力。** 先估算并用小规模调度或数据流检查验证：目标批大小、KV 头数、层数、页长及精度下，未满页缓冲占用多少容量；预填充时峰值到达速率和背压是否形成瓶颈。

必须区分全部逻辑缓存与真正驻留片上 SRAM 的部分，使用实际驻留层数与缓冲策略。比较全精度暂存在片上、暂存在片外，以及合理的分块或流水方案。不能把全部层的逻辑暂存直接算成片上需求。

**第二关：质量与收益。** 用比特精确实验检查候选尺度表示和重编码方法，在同一质量约束下是否减轻上述压力。纸面容量估算不能证明同等质量。显著性的判定依据目标平台约束和完整成本，阈值应在正式比较前记录。

两关均通过，且存在独立机制与设计规律时，W 独立成文；否则并入课题二。是否独立不影响写通路功能必须完成。

## 3. 研究内容

1. **尺度确定时机。** 比较全精度暂存后量化、随到达更新尺度、子组量化后合并，以及适用时的预先固定尺度基线。
2. **尺度表示。** 比较任意有限精度尺度、二次幂尺度、共享指数等候选方式，统一核算质量、运算与存储成本。
3. **原地重编码。** 研究 SRAM 内码字更新、零点修正、舍入、饱和和重复重编码误差，以及 bank 冲突和读写带宽。
4. **未满页读写。** 定义新 token 如何立即参与后续注意力、读取使用哪个尺度版本，以及重编码与读取冲突时如何处理。
5. **关闭页生成。** 按共同接口保留足够信息，接受最终配置并生成课题一规定的格式。统计提取、最终重编码和搬移开销单独计入。
6. **可选统计。** 软件阶段记录候选统计量；课题一验证其价值后，再实现必要部分并报告开销。暂不要求生成模式 C 的残差。

## 4. 重编码的算术约束

对表示 x_hat = s(q - z)，从旧码字的重建值生成新码字时，一般需要：

```text
q_new = clip(round((s_old / s_new) * (q_old - z_old) + z_new))
```

其中 s 是尺度，z 是零点；clip 为新比特档的饱和裁剪，round 使用共同模型规定的舍入方式。该式基于旧重建值，不表示恢复原始数据。

二次幂尺度比可以简化乘除，但不自动消除零点处理、舍入或饱和。共享指数能否使用移位重编码也必须由具体表示证明。误差评估要覆盖多次尺度更新，而不只验证一次转换。

## 5. 贡献边界与交付物

W 负责“数据如何到达、保留、重编码并写成合法页”。不研究统计量对任务质量的预测规律，不负责最终配置策略，不重复课题二的读出计算评估。

交付资源估算、尺度与重编码语义、误差结果、未满页缓冲和读写协议、关闭页生成流程、写通路实现及代价。合入课题二时，所有这些交付仍需存在。

## 并行开展与交接

可立即与课题一、二并行开展容量和带宽估算、暂存与重编码验证、未满页读写设计。无需等待统计预测结论；资源压力与质量收益两关通过后，再决定是否独立成文。

- 接收课题一的参数化格式及候选统计量；只在预测价值确认后实现必要的统计电路。
- 与课题二共同定义未满页读取与尺度更新接口。
- 向课题三提供决策时可用的信息、可生成配置集合和关闭页转换成本。
- 页满后选择更高精度或更细分组，必须以仍保留的信息为依据；不能从不可逆低比特表示任意恢复。
- 若合入课题二，功能与交付继续保留，取消的只是独立论文切分。

## 共同约束与接口

- 比特档为 2、4、8；以 K 按通道、V 按 token 的非对称均匀量化为共同基准，不以训练、微调或新量化公式为贡献。
- 页长在一次实验或实现内固定。配置必须能被页格式表达、由保留数据生成，并由实际通路执行。
- 使用共同的全精度质量参照、校准与测试划分、比特精确模型、硬件预算及完整成本口径。
- 初期保持参数化；最终实现与正式评估前共同冻结尺度语义、页生命周期、描述符、配置集合和成本接口。
- 模型、任务、质量预算和具体硬件参数尚待共同确定；本文描述研究目标，不表示已取得实验结果。
