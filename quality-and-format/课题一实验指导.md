### 3.2 前向精度

- 权重和注意力计算保持 checkpoint 的 bfloat16。
- 量化的 min、max、除法和舍入在 float32 中计算，尺度再舍入到存储格式。
- 反量化结果写回 cache 前转回 bfloat16。质量实验度量的是「存量化、算反量化后的 bfloat16」这条路径。低比特域乘加是课题二的问题，不在这里模拟。
- 质量实验的 batch size 为 1。任务评测若用更大 batch，先在 20 条样本上与 batch 1 的全精度得分对齐，差值超过预登记容差就退回 batch 1。

### 3.3 解码

量化比较的主协议是贪心解码：`do_sample=false`，使用模型自己的 EOS。这样同一条样本的全精度和量化是配对的，差值不混入采样噪声。

次协议只用于和已发表的全精度分数对照：把模型卡推荐的采样参数原样抄进 `generation_secondary.yaml`，固定一组种子。次协议的分数不作为「统一使用通过」的判定依据。DeepSeek-R1 蒸馏模型的已发表数学分数通常来自采样；对不上贪心分数是预期情况，在表注里说明协议，不调量化参数去追那个分数。

## 5. 页几何

### 5.1 定义

一条序列的 token 位置从 0 编号。页长 \(L_p\) 在一次运行内固定。页 \(p = 0,1,2,\ldots\) 覆盖

\[
\mathcal{T}_p = \{p L_p,\ldots,\min((p+1)L_p, N)-1\}.
\]

正式单页实验只用满页：\(|\mathcal{T}_p|=L_p\)。末尾不满的页进入「未满页」条件，只在 E0 检查布局，不进入敏感度分布。页关闭指这个满页的 K、V 都已经写入，并且之后不再追加 token。

K 与 V 使用同一页的 token 范围，但比特和组大小可以不同。配置

\[
c = (b_K, g_K, b_V, g_V, \text{scale\_fmt}).
\]

\(b_K, b_V \in \{2,4,8\}\)。

### 5.2 分组方向

这是共同基准，不是本课题要提出的新量化。

- **K 按通道。** 对每个 KV 头、每个头维坐标 \(m\)，沿页内 token 分组。组大小 \(g_K\)。一组是同一通道上连续的 \(g_K\) 个 token。
- **V 按 token。** 对每个 KV 头、每个 token，沿头维分组。组大小 \(g_V\)。一组是同一 token 上连续的 \(g_V\) 个通道。

cache 中的 K 是模型已经做过 RoPE 的 K。量化这个存储值。不另做一份 RoPE 前的 K，除非单独开一个标明的条件。

主网格让组大小整除对应维度，避免主结果依赖尾组：

| \(L_p\) | \(g_K\) | \(g_V\)（头维 128） |
| --- | --- | --- |
| 32 | 32 | 32、64、128 |
| 64 | 32、64 | 32、64、128 |
| 128 | 32、64、128 | 32、64、128 |

\(g_K = L_p\) 表示该通道在整页只有一个尺度。这个配置是课题二问「尺度能否移出页内求和」时必须回测的质量点，所以留在主网格里。尾组语义仍然要单测：组大小不整除时，最后一组用剩余元素单独做 min/max，不把下一页的 token 补进来，也不复制元素。

### 5.3 位置桶

对一次查询位置 \(t\)（正在预测的那个 token 的位置），页 \(p\) 的距离

\[
d(t,p) = t - \max\mathcal{T}_p.
\]

\(d \le 0\) 表示页尚未关闭，本课题的单页标签不使用这种查询。已关闭页：

| 桶 | 规则 | 备注 |
| --- | --- | --- |
| `sink` | \(p = 0\)，即含位置 0 的页 | 即使 \(d\) 落在近期窗口内也算 `sink`，不重复计入 `recent` |
| `recent` | \(p \ge 1\) 且 \(0 < d \le W\) | 主窗口 \(W = 128\)。边界 \(d = 128\) 属于 `recent` |
| `mid` | \(p \ge 1\) 且 \(d > W\) | 中间历史页。T-Retrieval 只用这个桶 |

\(W\) 是分析坐标，不是 KIVI 的残差窗口。和 KIVI 对照时，KIVI 使用它自己论文和所钉提交里的残差长度，另记一列。

一个页在整段答案上的桶，按答案 token 的查询位置分别记录，再汇总。分布实验的主汇总是：该页在答案 token 上出现过的最敏感桶（优先级 `sink` > `recent` > `mid`），同时保留每个查询的细表。不要只在最后一个 token 上判桶。

### 5.4 候选配置

主候选是下面这个集合与第 5.2 节组大小的乘积，尺度格式先用 `fp16`：

- 统一档：K 与 V 同比特、同组大小。比特取 8、4、2。
- 不对称比特：`(b_K,b_V)` 取 `(4,2)`、`(8,4)`、`(8,2)`、`(2,4)`。最后一档用于检验「把精度让给 V」是否更差，不是预期的部署档。
- 尺度格式附加档：只在 P1 选定的一个 2-bit 细组和一个 2-bit 粗组上，比较 `fp16`、`bf16`、`e8m0` 三种尺度存储。零点始终是整数。

P2 可以把主候选收窄，但收窄规则写在预登记里，理由来自 P0 和 P1 的数值或耗时，不来自 `D_test`。

## 6. 黄金量化

### 6.1 数值语义

一组元素 \(x \in \mathbb{R}^{n}\)，比特 \(b\)，\(q_{\max} = 2^b - 1\)。存储尺度用 IEEE 舍入到 `scale_fmt`（主格式 float16，舍入到最近偶数）。整数零点用舍入到最近偶数，半数趋向偶数；实现用 `torch.round` 时要核对它的半数行为，并在单测里钉死。

规程如下。\(x\) 先转 float32。

1. \(x_{\min} = \min x\)，\(x_{\max} = \max x\)，\(\mathrm{range} = x_{\max} - x_{\min}\)。
2. 若 \(\mathrm{range} = 0\)：尺度字段存 float32 的 \(x_{\min}\) 再舍入到存储格式，零点存 0，码字全 0。反量化时广播这个尺度字段。常量组的重建误差只来自存储格式对 \(x_{\min}\) 的舍入。
3. 否则 \(s = \mathrm{cast}(\mathrm{range} / q_{\max})\)。若 cast 后 \(s = 0\)（下溢），按常量组处理，尺度字段存 \(\mathrm{cast}(x_{\min})\)。
4. \(z = \mathrm{clip}(\mathrm{round}(-x_{\min} / s),\, 0,\, q_{\max})\)。
5. \(q = \mathrm{clip}(\mathrm{round}(x / s + z),\, 0,\, q_{\max})\)，\(q\) 为整数。
6. 反量化 \(\hat x = \mathrm{cast_{bf16}}(s \cdot (q - z))\)。乘加在 float32，写回前转 bfloat16。

常量组不能用「尺度加一个很小的 epsilon 再夹紧零点」代替。那种做法在大幅值常量上会饱和到错误的重建值。常量组规则要进解包器：`z == 0` 且码字全 0 时，输出尺度字段的广播。单测覆盖一种碰撞：非常量组刚好量化成全 0 且零点为 0。若出现，日志记 `degenerate_collision`，质量实验仍按上面的解码规则执行，并在论文里报告碰撞次数。P1 若碰撞比例超过 \(10^{-4}\) 组，停下来改编码（给常量组一个显式标志位），升协议版本。

`e8m0` 尺度是 2 的幂。第 3 步的 \(s\) 改为不小于 \(\mathrm{range}/q_{\max}\) 的最小 2 的幂，再走第 4–6 步。它不是「先按实数尺度量化，再把尺度舍入」。二次幂尺度只改变存储的 \(s\)，不取消零点和饱和。

### 6.2 参考实现约束

参考实现放在实验代码的 `quant/golden.py`，与下面的单测一起版本化。伪代码只固定语义：

```python
def quantize_group(x_bf16, bits, scale_fmt):
    x = x_bf16.float()
    qmax = (1 << bits) - 1
    xmin, xmax = x.min(), x.max()
    if float(xmax - xmin) == 0.0:
        return constant_group(xmin, scale_fmt)  # q = 0, z = 0, xhat = cast(xmin)
    s = cast(xmax - xmin, scale_fmt) / qmax
    s = cast(s, scale_fmt)
    if float(s) == 0.0:
        return constant_group(xmin, scale_fmt)
    z = int(clip(round_nearest_even(-xmin / s), 0, qmax))
    q = clip(round_nearest_even(x / s + z), 0, qmax).to(torch.int32)
    xhat = cast_bf16(s.float() * (q.float() - z))
    return q, z, s, xhat
```

`constant_group` 的尺度字段是 \(\mathrm{cast}(x_{\min})\)，不是步长。解包函数和打包函数使用同一规则。

### 6.3 必须通过的单测

每条单测用固定种子生成输入，断言精确张量，不用「误差大概很小」。

1. **往返恒等条件**：全 0 组、全常量组、已经落在重建格点上的输入，反量化后与 bfloat16 原值按位一致。
2. **范围**：码字在 \([0, q_{\max}]\)，零点在 \([0, q_{\max}]\)，重建值落在 \([\mathrm{cast}(x_{\min}), \mathrm{cast}(x_{\max})]\) 的可表示范围内（允许 bfloat16 舍入一个 ulp）。
3. **尾组**：长度 64、组大小 48，得到长度 48 和 16 的两组，第二组的 min/max 与手工切片一致。
4. **方向**：同一个张量 `[token, channel]`，K 路径的组和 V 路径的组不同。用一个只在单个通道上有尖峰的张量检查：K 按通道时尖峰只撑大该通道的尺度；V 按 token 时尖峰撑大该 token 上含该通道的那一组。
5. **跨页**：页边界两侧的元素不进同一组。
6. **写回**：反量化相对 float32 重建的差异等于 bfloat16 舍入，不多一次。
7. **哈希**：同一输入、同一配置，打包字节的 SHA-256 稳定。

单测输出写入 `runs/p0/quant_tests.json`。正式运行的日志引用这个文件的哈希。

## 7. 存储格式与字节模型

### 7.1 页内布局

一页在 DRAM 上分成两段，K 段和 V 段各自按突发长度对齐。描述符不放在页数据里，放在页表项中。

每组元数据：主格式为 float16 尺度 2 字节加 uint8 零点 1 字节，再按 2 字节对齐成 4 字节。零点只用到 \(b\) 比特，uint8 足够覆盖 2/4/8 比特。对齐填充计入字节模型。`e8m0` 条件改为 1 字节尺度加 1 字节零点，组元数据 2 字节，同样记录填充。

K 的组数：

\[
N_{g,K} = H_{\mathrm{dim}} \cdot \lceil L_p / g_K \rceil.
\]

V 的组数（满页）：

\[
N_{g,V} = L_p \cdot \lceil H_{\mathrm{dim}} / g_V \rceil.
\]

码字字节：

\[
B_{K} = L_p \cdot H_{\mathrm{dim}} \cdot b_K / 8, \qquad
B_{V} = L_p \cdot H_{\mathrm{dim}} \cdot b_V / 8.
\]

主格式元数据字节 \(M_K = 4 N_{g,K}\)，\(M_V = 4 N_{g,V}\)。突发长度 \(A \in \{32, 64\}\) 字节，主报告用 \(A = 64\)：

\[
B_{\mathrm{DRAM}}(c) = \lceil (B_K + M_K) / A \rceil A + \lceil (B_V + M_V) / A \rceil A.
\]

有效位宽按该 KV 头这一页的全部 K 元素和 V 元素计：

\[
b_{\mathrm{eff}}(c) = \frac{8\, B_{\mathrm{DRAM}}(c)}{2 \cdot L_p \cdot H_{\mathrm{dim}}}.
\]

全精度参照是同一页 K 与 V 的 bfloat16 存储，\(B_{\mathrm{FP}} = 4 \cdot L_p \cdot H_{\mathrm{dim}}\) 字节，再按同样的 \(A\) 对齐。压缩比用对齐后的字节相除。

2 比特、float16 尺度、uint8 零点、4 字节组元数据时，元数据与码字之比是 \(32 / (g \cdot 2) = 16/g\)：\(g = 32\) 为 50%，\(g = 64\) 为 25%，\(g = 128\) 为 12.5%。这是本格式的算术结果。论文里的字节数以程序算出的 \(B_{\mathrm{DRAM}}\) 为准，手算只用于单测。

### 7.2 描述符

64 位。字段在 P0 定死，正式实验中途不加字段。

| 位 | 宽度 | 字段 | 取值 |
| --- | --- | --- | --- |
| 0–1 | 2 | `b_K` | 0→2，1→4，2→8，3 保留 |
| 2–3 | 2 | `b_V` | 同上 |
| 4–5 | 2 | `g_K` | 0→32，1→64，2→128，3 保留 |
| 6–7 | 2 | `g_V` | 同上 |
| 8–9 | 2 | `scale_fmt` | 0→fp16，1→bf16，2→e8m0，3 保留 |
| 10–11 | 2 | `mode_QK` | 课题二填写。课题一质量实验固定 0，表示反量化后按 bfloat16 计算 |
| 12–13 | 2 | `mode_PV` | 同上 |
| 14–15 | 2 | `page_state` | 0 空，1 追加中，2 关闭已提交，3 保留 |
| 16–23 | 8 | `valid_tokens` | 0–255。主实验满页等于 \(L_p\) |

### 7.3 打包单测

对每个主候选配置：

- 打包再解包，与第 6 节直接反量化的 bfloat16 按位一致。
- 程序计算的 \(B_{\mathrm{DRAM}}\)、\(b_{\mathrm{eff}}\) 与一份手工例子一致。手工例子至少包括：\(L_p=64\)，\(H_{\mathrm{dim}}=128\)，\(b_K=b_V=2\)，\(g_K=g_V=64\)，\(A=64\)。
- K 段和 V 段的起始地址都是 \(A\) 的倍数。
- 描述符 round-trip 后字段不变。

E0 的产品是一张表：每一行一个配置，列包括码字字节、元数据字节、对齐填充、\(B_{\mathrm{DRAM}}\)、\(b_{\mathrm{eff}}\)、相对 bfloat16 的压缩比。这张表是 E4 的预算坐标。没有这张表，任务分不能对「比特数」作图。

## 8. 三种干预

三层指标对应三种不同的计算。日志字段 `intervention` 只能取下面三个值。论文里的每张图都要写明是哪一种。

### 8.1 `recon`：重建误差

用全精度一次前向写出的 cache。对选定页、选定配置做量化和反量化。不重新跑后续 token。

这一层回答「这个页的数值被改了多少」，不回答任务会不会错。

### 8.2 `local_attn`：单层局部注意力

在选定层挂住该层的 Q、K、V（K、V 为已 RoPE、已写入 cache 的值）。只把目标页的 K 和/或 V 换成反量化值，用原有的 Q 重算选定查询位置的注意力输出。后续层不再前向。误差不进入下一步的 cache。

这一层对应该笔记里的 \(\Delta a\) 和 \(\Delta o\)，也对应「扰动不传入后续层」的局部协议。它不是端到端敏感度。

查询位置的抽法在第 10 节。每个查询头单独算，再对同一 KV 头取平均和最大。

### 8.3 `closure_fork`：页关闭分叉

这是端到端单页标签的唯一定义。

对满页 \(p\)、配置 \(c\)、样本 \(u\)：

1. 全精度前向到页 \(p\) 刚写满的位置 \(t_{\mathrm{close}} = \max\mathcal{T}_p\)。保存此时的 cache。
2. 立刻把该页指定的张量（仅 K、仅 V、或 K 和 V）替换为按第 6 节反量化并转回 bfloat16 的值。记录打包字节的 SHA-256。
3. 从位置 \(t_{\mathrm{close}}+1\) 继续前向，读到这一页时始终用第 2 步的值。之后各层、各个新 token 写出的 K、V 按真实前向更新。
4. 未选中的、位置早于或等于 \(t_{\mathrm{close}}\) 的其他页保持全精度原值，不用扰动后的隐藏状态去重写它们。
5. 答案段与全精度轨迹使用同一条标准答案前缀（teacher forcing）计算负对数似然。自由生成另开一条轨迹，不混进 \(S\)。

禁止的做法：先把整段全精度跑完，只在最后一个问题 token 上替换历史页。那会漏掉该页对后续 cache 的传播。

多页同时量化用 `closure_fork_joint`：所有被选中的页都从**原始全精度 cache** 量化，然后从最早一个被选中页的下一 token 重算。被选中页的量化输入是干净页，不是已经带误差的重算页。这个定义回答「这些页若按各自干净内容被量化，一起运行会怎样」。它和「前一页的误差改变后一页的写出值，再量化后一页」不是同一个实验。后者标成 `sequential_online`，只作为附录条件，不作为主标签。

`closure_fork` 的实现检查：

- 同一页、同一配置、两个问题，若分叉点在公共前缀之内，两问读到的该页字节哈希相同。
- 替换发生在 \(t_{\mathrm{close}}\) 之后的第一次读取，包括公共前缀的剩余部分，不只在问题句。
- 全精度轨迹不读取任何量化字节。全精度按 `(model, sample_id, prompt_hash)` 缓存，可跨层、头复用。

## 9. 指标

### 9.1 重建

对一页的 K（V 同样）：

\[
\mathrm{rel}_K(p,c) = \frac{\lVert \hat K - K \rVert_F^2}{\lVert K \rVert_F^2 + \varepsilon}, \qquad \varepsilon = 10^{-12}.
\]

另报每通道 \(\lVert \Delta K_{:,m} \rVert_\infty\) 的最大值和 95 分位。分母用全精度 bfloat16 张量。分子用写回 bfloat16 后的差。

### 9.2 局部注意力

对每个查询头 \(h\)、查询位置 \(t\)：

- 注意力权重的 L1：\(\lVert a^{(\mathrm{fp})} - a^{(c)} \rVert_1\)。
- 注意力输出的相对误差：\(\lVert o^{(\mathrm{fp})} - o^{(c)} \rVert_2 / (\lVert o^{(\mathrm{fp})} \rVert_2 + \varepsilon)\)。

KV 头的主标签取组内查询头的最大值，辅标签取均值。同时记录组内查询头之间的 Spearman，用来检验机制笔记里「高误差通道在组内对齐」这一假设。

### 9.3 端到端负对数似然增量

标准答案 token \(y_1,\ldots,y_T\)，两条轨迹使用同一前缀和同一答案历史：

\[
S(p,c;u) = \frac{1}{T}\sum_{\tau=1}^{T}
\log \frac{P_{\mathrm{fp}}(y_\tau \mid u, y_{<\tau})}{P_{p,c}(y_\tau \mid u, y_{<\tau})}.
\]

单位是 nats/token。\(S > 0\) 表示量化降低了标准答案的概率。负值原样保留，不截断。\(T\) 用答案 token 数，不用整段序列长度。

关键步 \(S_{\mathrm{key}}\) 使用同一公式，但求和只包括预登记时标出的答案区分 token。数学题用最终答案的数字或选项 token；检索题用被问事实的答案 token。整题只有一个答案 token 时 \(S = S_{\mathrm{key}}\)。\(S_{\mathrm{key}}\) 的标注规则写在数据清单里，由不看量化结果的脚本根据标准答案生成。

自由生成的对错另报，不并进 \(S\)。

### 9.4 任务分

官方指标，全缓存按某种分配量化之后、贪心生成得到。单页 \(S\) 不能换成任务分，任务分也不能反过来说成某一页的敏感度。

通过与否只看任务分和第 16.1 节的预算。\(S\) 用于解释和训练预测器。

### 9.5 统计

页不是独立样本。同一条序列里的页相关。所有置信区间用**按序列聚类的 bootstrap**：有放回地抽取序列，抽到的序列带走它的全部页，重复 2000 次，取 2.5 和 97.5 分位。随机种子 `bootstrap_seed = 20261118`。

秩相关用 Spearman。比较两个嵌套特征集时，对每次 bootstrap 样本计算 \(\rho(F_{\mathrm{big}}) - \rho(F_{\mathrm{small}})\)，报告这个差值的区间。不报告把页当成独立样本的 p 值。

配对比较（同一页的仅 K 与仅 V，或同一页的两个问题）在序列内部先平均，再对序列做配对 bootstrap。

方差分解用预登记的因素：模型（分层做，不作为一个随机效应去平均）、层、KV 头、位置桶、任务族。在 `local_attn` 的输出相对误差和 `closure_fork` 的 \(S\) 上分别做。报告每个因素的偏 \(R^2\)，并给聚类 bootstrap 区间。这是描述分布的主表，不是显著性清单。

### 10.2 计时表

P1 记录下面每一格的墙钟时间和峰值显存。外推时把「每条序列的前缀长度」写进去，不用一个总 GPU 小时去估。

| 操作 | 记录 |
| --- | --- |
| 全精度前缀 + 答案 NLL | 秒/序列，按长度分箱 |

分布块的重算次数大约是：

\[
N_{\mathrm{fork}} = N_{\mathrm{layer}} \times N_{\mathrm{kv}} \times N_{\mathrm{seq}} \times N_{\mathrm{page}}.

## 11. 页关闭特征

特征只能使用该页写满时已经存在的量。实现按下面的集合分别出列，便于做嵌套比较。

### 11.1 `F0` 坐标

层号、KV 头号、页号、`sink`/`recent`/`mid`、该层 KV 头在 `D_cal` 上的平均 `local_attn` 误差和平均 \(S\)。后两个平均值是校准统计，不是本页的未来信息。计算某条 `D_cal` 样本的特征时，用留一的其余 `D_cal` 样本，避免自己预测自己。`D_sel` 和 `D_test` 使用全部 `D_cal` 的平均。

硬件成本：层号、头号、页号和位置桶来自分页计数器。校准平均是一张只读小表。

### 11.2 `F1` 量化副产物

对当前配置真正会使用的每个组：min、max、尺度、零点。页级汇总：

- 组尺度的最大值、中位数、最大值/中位数。
- K 的按通道尺度向量的稀疏度：最大尺度与尺度中位数之比。
- 常量组所占比例。

这些量在量化本身的 min/max 里已经出现。页级汇总是一次对组尺度的归约。

`F1` 预测 T-Group 的方式要简单：用更细的子组尺度比估计放宽组大小后的步长。例如 \(g=32\) 的相邻两组若合并成 \(g=64\)，合并组的 range 至少是两组 range 的较大者，至多是两组合并后的真实 range。P0 实现「由细组 min/max 精确计算粗组 min/max」这一不看未来的量，作为 T-Group 的主要特征。它需要细组的 min/max，不需要把原始张量再扫一遍以外的数据；若量化器本来就按细组工作，这是已有寄存器的二次归约。

### 11.3 `F2` 流式伴随量

随 token 写入累加，不保留第二份高精度页：

- \(\sum |x|\)、\(\sum x^2\)，按 K 的通道和 V 的 token 分开。
- 峰均比：\(\max |x| / (\mathrm{mean}|x| + \varepsilon)\)。
- 离群计数：\(|x| > \tau \cdot \mathrm{median}|x|\) 的元素个数。\(\tau \in \{8, 32\}\)，两个都记，阈值在 P2 从这一对里选一个，选择依据是 `D_sel` 上的 T-Group 秩相关。
- 窗内查询幅值。该页 token 在本层被作为查询参加注意力时，Q 已经算过。对通道 \(m\)，

\[
\mathcal{I}_m = \frac{1}{|\mathcal{T}_p|}\sum_{i \in \mathcal{T}_p} |Q_{i,m}|.
\]

只累加本页 token 的 Q，不累加页关闭之后的查询。页级分数用 \(\sum_m \mathcal{I}_m s_{m}\)，其中 \(s_m\) 是该 K 通道的尺度。这是机制笔记里 \(\mathcal{A}_d = \mathcal{I}_d \mathcal{S}_d\) 的页内版本。

\(\mathcal{I}_m\) 对 T-Retrieval 的用处是一条假设，不是规程。实验要测的是：它相对 `F1` 的尺度，在 T-Group 和 T-Retrieval 上的增量是否不同。

硬件记录：需要每通道两个累加器和一个本页 Q 的绝对值累加。不需要保存原始 K、V。

### 11.4 `F3` 重扫描

页关闭时仍保留 bfloat16 原值，对每个候选 \((b,g)\) 再量化一次，记录 `recon` 和该页 token 作为查询时的 `local_attn`。这是写侧信息上界，不是主策略。日志里把它和 `F0`–`F2` 分开。课题 W 的成本说明写「需要保留整页高精度并做多配置扫描」。

### 11.5 明确不使用的量

下面的量可以计算，但只能放在 `oracle` 列，不能进入 `F0`–`F3`：

- 页关闭之后任何查询的注意力权重、包括 \(M_p\)。
- 答案 token 上的损失对 K、V 的梯度。
- 用未来问题才能知道的「这一页是不是证据页」。

预测器代码按列名读取特征。单元测试构造一个页，在关闭后修改未来查询，断言 `F0`–`F3` 的数值不变。

## 12. 模块步骤

### 12.1 E0 格式与黄金模型

**输入。** 第 5–7 节。

**步骤。**

1. 实现黄金量化和打包，通过第 6.3、7.3 节单测。
2. 生成主候选的字节表。
3. 附加数值条件，各用 `D_cal` 里 8 条序列的 `recon` 与 `local_attn`，不跑任务分：
   - 尺度格式 `fp16`、`bf16`、`e8m0`。
   - 重编码一次：细组 \(g=32\) 量化后，用 \(q_{\mathrm{new}} = \mathrm{clip}(\mathrm{round}((s_{\mathrm{old}}/s_{\mathrm{new}})(q_{\mathrm{old}}-z_{\mathrm{old}})+z_{\mathrm{new}}))\) 合并到 \(g=64\)，与「原值直接量化到 \(g=64\)」比较 `recon`。这是给课题 W 的误差预算，不是写通路设计。

**完成。** 单测哈希和字节表都在，并且有一行手工例子与程序一致。

### 12.2 E1 三层是否同序，多页是否可加

**输入。** P1 面板，配置 `K4V4, g=64` 与 `K2V2, g=64`。

**步骤。**

1. 同一批页上取 `recon`、`local_attn`、`closure_fork` 的 \(S\)。
2. 在「全部页」和「固定层、头之后的页」两个范围计算 Spearman，bootstrap 区间按序列聚类。
3. 多页可加性。在 24 条长度至少 2048 的序列上，从 `mid` 桶抽取互不相邻的页。集合大小取 1、4、16。对每个集合计算 `closure_fork_joint` 的 \(S_{\mathrm{joint}}\) 和单页 \(S\) 之和。报告

\[
\eta = S_{\mathrm{joint}} / \sum_i S_i
\]

的中位数和区间。分母绝对值小于 \(10^{-4}\) 的序列单独计数，不参与除法。

4. 在同一页上比较仅 K、仅 V、K+V 三者的 \(S\)。K+V 与仅 K 加仅 V 的差作为交叉项的经验大小。

**可以写的结果。** 在某个模型、某个配置上，三层指标的秩相关是多少、区间是否离开 0；\(\eta\) 随页数如何变化。相关高，才把 `local_attn` 用作更大面板上的代理，并在论文里写出这个适用条件。相关低，正式预测标签改用 `closure_fork` 的小面板，不把局部误差叫作任务敏感度。

**完成。** 一张秩相关表和一张 \(\eta\) 表，都带区间。

### 12.3 E2 四轴分布与两个对照

#### 层、头、K/V

用分布块和配对面板。

1. 层曲线：每个层把 KV 头先取最大，再对序列和页平均。画 `local_attn` 和 \(S\) 两条，不要合成一条。
2. 头：在每个层内把 KV 头按 `local_attn` 排序，看这个排序在任务族之间的 Spearman。
3. 同一页、同一比特、同一组大小，比较仅 K 与仅 V 的配对 \(S\)。
4. 记录该 KV 头在答案查询上的 \(a(1-a)\) 均值，作为事后解释变量。它来自全精度注意力，是 oracle 解释，不进入 `F0`–`F3`。假设是：仅 K 比仅 V 更差的那些头，\(a(1-a)\) 更大。检验用按序列聚类的相关，不是挑一个头做例子。

#### 起始页的 2×2

对象是页 0 里的位置 0，配置为 2 比特和 4 比特各做一遍，\(g_K=g_V=64\)。四个条件：

| 条件 | 位置 0 的值 | 其他组的 min/max |
| --- | --- | --- |
| `in` | 进入低比特组 | 包含位置 0 |
| `scale_isolated` | 进入低比特，使用**不包含位置 0** 的组尺度和零点，因此可能饱和 | 不包含位置 0 |
| `token_fp` | 保持 bfloat16 | 包含位置 0，尺度被它影响 |
| `page0_8bit` | 整页 0 用 8 比特、\(g=32\) | 按 8 比特页自己的组 |

`scale_isolated` 在 \(g_K\) 整除且位置 0 单独成组时，K 方向会和「位置 0 自己一组」重合。主实验仍用 \(g=64\)，并额外做一档 \(g_K=32\)，使位置 0 与同页其他 token 有机会同组。两种组大小都报告。

这个实验用 `closure_fork`，序列至少 24 条，任务含一个检索任务和一个数学任务。主终点是四个条件的 \(S\) 和全缓存只改页 0 时的任务分差。全缓存那一次只把页 0 按该条件量化，其余页全精度。

要回答的实施问题：页 0 整页升到 8 比特，相对「只把位置 0 留在全精度」，在任务分上差多少。这决定格式要不要支持页内逐 token 稀疏精度。

#### 等字节的位置对照

高精度页的比例 \(\alpha \in \{0.05, 0.10, 0.20\}\)。高精度配置固定为 `K8V8, g=32`，其余页为 `K2V2, g=64`。字节用 E0 的表计算，三个策略使用同一 \(\alpha\)，所以字节预算相同。策略：

1. 只保护页号最小的那些页。
2. 只保护距离生成终点最近的已关闭页。生成长度不固定时，用「问题开始前的最后 \(\alpha\) 比例页」作为可执行的定义，并在预登记里写明。不要用生成过程中才知道的未来长度去选页。
3. 页 0 加上最近页，总数仍是 \(\alpha\) 比例；页 0 占去一名额。
4. 随机页，三个种子 `20261114`、`20261115`、`20261116`。
5. 在序列前半的已关闭页里均匀间隔抽取。

评测是全缓存任务分，不是单页 \(S\)。样本用 `D_sel` 做探索、`D_test` 做一次正式。正式只跑预登记里写明的 \(\alpha\)（默认 0.10）和五个策略。

同时统计全精度轨迹里每个已关闭页在答案查询上被读取的次数，作为 \(N_{\mathrm{read}}\) 的经验分布。课题一不把读取次数乘能量系数；把分布交给课题三。读取次数的定义是：答案每个 token、每一层都读取该页一次。这是结构计数，不是仿真器的周期数。

**完成。** 每个模型一张层–头表、一张 2×2 表、一张等字节位置表。表里是区间，不是单点。

### 12.4 E3 预测力与同页配对

#### 嵌套预测器

主预测器是可解释的、在 `D_cal` 上拟合的单调分数，不用黑箱模型做主结论。

- `M0`：\(F0\) 的校准表。分数等于该 \((\mathrm{layer}, \mathrm{head}, \mathrm{bucket})\) 的留一平均标签。
- `M1`：\(M0\) 加上 `F1` 的组尺度比和「细组推出的粗组 range」。系数非负，在 `D_cal` 上用最小二乘拟合，负系数截断为 0 后不再迭代寻找。
- `M2`：`M1` 加上峰均比、预登记的那个 \(\tau\) 的离群计数、以及 \(\sum_m \mathcal{I}_m s_m\)。同样非负系数。
- `M3`：`M2` 加上 `F3` 的真实重建误差。这是重扫描上界。
- `G`：同一特征上的梯度提升树，`D_cal` 拟合。它是特征集合的灵活上界，不是要交给硬件的策略。若 `M2` 的 Spearman 低于 `G` 的 0.8 倍，结论写成「特征里有信息，但预登记的线性规则没取到」，不把 `G` 的分数写成页关闭策略的分数。0.8 这一档在 P2 就写死。

标签：

- T-Group 的标签是同一页 `g=32` 与 `g=128` 的 `local_attn` 之差（比特固定为 2，以及重复一档比特 4）。E1 若表明 `local_attn` 与 \(S\) 在这个面板上的 Spearman 低于 0.5，标签改成配对面板上的 \(S\) 之差，并缩小配置范围。
- T-Retrieval 的标签是 `mid` 桶页的 \(S\)，配置 `K2V2, g=64`。`sink` 和 `recent` 不进这个标签。

正式比较是 `D_test` 小面板上 \(\rho(M1)-\rho(M0)\)、\(\rho(M2)-\rho(M1)\)、\(\rho(M3)-\rho(M2)\) 的聚类 bootstrap 区间。T-Group 和 T-Retrieval 各报各的。

阈值不在这个相关分析里选。相关分析用连续分数。真正用来分配配置的阈值属于 E4，在 `D_sel` 上选。

#### 同页配对

目的：给 T-Retrieval 的负结果一个机制，而不是只给一个低相关系数。低相关本身不够成文。

**条目构造。**

1. 从 `D_cal` 的长上下文里取真实文本作载体，打乱载体与事实的搭配。载体长度至少 2048，且是 \(L_p\) 的整数倍。
2. 两条事实使用不可能来自预训练记忆的随机代号，例如项目名与校验码。事实 token 必须完整落在一个 `mid` 页内，不跨页，不落在页 0，不落在问题前 \(W\) 个 token。
3. 两个问题分别只问其中一条事实。另有一个控制问，答案不在任一事实里（算术题）。控制问用来确认量化没有把模型全局打坏。
4. 交换两条事实所在的页，做成配对的第二份条目，抵消页位置本身的难易。
5. 问题有两个措辞：与事实共享关键词的措辞，以及改写后的措辞。两个都做，结果分开。

**轨迹。**

对页 A、页 B 各做一次 `closure_fork`，配置在 P2 定为 `K2V2, g=64`（若全精度在该载体上的答案已经不稳定，先缩短载体或换事实位置，不改量化来「修好」）。分叉点在两条事实都写完之后、问题之前。问 A 和问 B 复用同一份页字节。

**纳入。** 全精度贪心必须答对事实。答错的条目剔除，并报告剔除率。剔除率超过 50% 时，这个构造失败：修改事实格式或载体长度，升版本，在新的 `D_cal` 样本上重做。不要用答错的条目去算敏感度。

**终点。** 对保留条目，

\[
\Delta S(A) = S(\text{页 A}; \text{问 A}) - S(\text{页 A}; \text{问 B}).
\]

同样定义 \(\Delta S(B)\)。页 A 的 `F0`–`F3` 在问 A 和问 B 上必须按位相同；单测比较特征哈希。主结果是 \(\Delta S\) 的中位数及其配对区间。

**和自然文本的关系。** 构造条目里的检索率是实验者设定的。另在 LongBench 多文档问答上做自然条目：证据 span 与页的重叠由数据集标注决定，不由实验者挑选。一页标成 `needed`，当且仅当它与官方证据 span 重叠。这个标注有噪声，所以同时报告全精度注意力质量落在证据页内的比例。自然条目上的 \(\Delta S\) 是外推检查。构造条目上的效应不能写成真实负载里高敏感页的比例。

**样本目标。** 每个模型先准备 80 个构造条目。剔除后若任一项少于 40 个保留条目，补构造，仍只用 `D_cal` 的载体。正式推断用这批保留条目；若还要报 `D_test` 载体上的复现，载体划分遵守第 4 节，事实仍是新的随机代号。

#### 这一模块怎样才算做完

- 两张嵌套相关表：T-Group、T-Retrieval。
- 同页配对的 \(\Delta S\) 区间，加上自然条目的同一区间。
- 一份特征成本说明：每个特征集合对应「已有量化寄存器 / 流式累加 / 必须保留高精度页」。

### 12.5 E4 配置筛选与离线分配

#### 全缓存评测

每个正式分配都是「每个已关闭页一个配置」。未关闭的当前页保持 bfloat16。这与「近期窗口不量化」不同；若某个分配保护的是问题开始前的最后几页，按 E2 的可执行定义，不要在生成过程中把已经提交的页改回高精度。

评测集合是 `D_test`。每个分配跑一遍官方任务。生成长度、停止符和打分器与全精度守门时相同。

#### 五个分配

全部使用 E0 的 \(B_{\mathrm{DRAM}}\)。比较之前先在表里列出每个分配的实际字节，不要假定它们字节相同。

| 代号 | 分配 | 用到的信息 |
| --- | --- | --- |
| `S0` | 统一配置。预登记的网格，不是只挑最好的一个 | 无 |
| `S1` | 每个 \((\mathrm{layer},\mathrm{head})\) 在 `D_cal` 上选一个比特对，组大小固定为 64。选择规则：在 `D_cal` 的探针上满足预算的最低字节 | 校准表 |
| `S2` | `S1` 再加 E2 正式选定的位置规则（哪个 \(\alpha\)、哪种位置策略，由 `D_sel` 决定） | 坐标 |
| `S3` | `S2` 的比特不再改动。页关闭时只用 `M1` 或 `M2`（取 `D_sel` 上 T-Group 更好的那个）决定该页的 \(g\) 是否从 32 放到 128，以及 2 比特页是否必须退回 4 比特。退回规则若触发，字节会上升，必须计入 | 关闭时特征 |
| `S4` | 下面的面板 ILP | 未来信息，图上用另一种线型 |

`S3` 的规则在 `D_sel` 上选定之后写死。`D_test` 上只跑这一条 `S3`，不跑一簇阈值。

#### 面板上的离线最优

只在有 `closure_fork` 标签的页面板上做整数线性规划。决策变量 \(x_{p,c}\in\{0,1\}\)，每个页恰好一个配置：

\[
\begin{aligned}
\min_x \quad & \sum_{p,c} S(p,c)\, x_{p,c} \\
\text{s.t.}\quad & \sum_c x_{p,c} = 1, \\
& \sum_{p,c} B_{\mathrm{DRAM}}(c)\, x_{p,c} \le B.
\end{aligned}
\]

\(S(p,c)\) 是该页的单页标签。求解器用 HiGHS 或 CBC。记录最优性间隙。间隙为 0 的解，称作**这个面板、这个单页目标、这个字节上限下的离线最优**。不要称作任务质量的全局最优，也不要称作在线策略。

把求解用的 \(S\) 换成 `local_attn` 时，解的名字改成 `S4_local`。两个解的差别本身是结果：它说明代理目标会不会选错页。

面板之外的页怎么办要写进预登记。默认：面板外的页使用 `S2` 的层头配置，不把它们假装放进了 ILP。因此整段序列的任务分是「面板最优加上面板外的 S2」，在表里就用这个名字。

小面板核对：抽 8 页、每个页 4 个配置，穷举与求解器对照，最优值必须一致。这个核对进 P0。

#### 外部参照

同一模型、同一任务、同一贪心协议下报告：

- 全精度。
- 统一 8 比特、统一 4 比特、统一 2 比特，组大小与所钉的 KIVI 提交一致，并另报本格式 \(g=64\) 的统一档。两套组大小不要混成一个点。
- KIVI：使用作者仓库的钉死提交，保留它的按通道 K、按 token V 和残差窗口。标注「原方法」。
- 层级混合：用本格式实现「每层一个比特、校准集上选择」的移植版，标注「移植」。不把移植版的分数写成原论文的分数。
- 通道级混合只作为上界参照时，必须来自可运行的原仓库或明确的移植，并单独说明它的访存不是本页格式。

不满足第 16.1 节预算的点可以画在图上，标记为不可行，不与可行点比「谁的分数更高」。

#### 筛选状态

对每个候选配置和每个模型：

| 状态 | 含义 |
| --- | --- |
| `uniform_pass` | 所有页都用它，在 `D_test` 上满足第 16.1 节预算 |
| `mixed_pass` | 统一使用不满足，但某一个预登记的混合协议满足。协议的名字、混合比例和选页规则写在同一行 |
| `tested_fail` | 上述已测协议都不满足 |
| `untested` | 没有按规程跑过 |

`tested_fail` 的覆盖范围（模型、任务、协议）写在格子里。不把一个模型上的失败写成所有模型不可用。

## 16. 预先登记的判定

阈值在看 `D_test` 之前写进第 15 节的文件。下面是建议的初值；若 P1 表明某项任务的全精度置信区间半宽已经大于该阈值，把该项标成 `underpowered`，不把阈值放宽去迁就它。

### 16.1 任务预算

「下降」指全精度分数减方法分数，单位与官方分数一致（准确率用百分点）。95% 区间来自样本级配对 bootstrap。

一个分配对一个模型 `uniform_pass` 或 `mixed_pass`，当且仅当同时满足：

- GSM8K 下降的区间上界 \(\le 1.0\) 个百分点；
- MATH-500 下降的区间上界 \(\le 1.5\) 个百分点；
- 每个纳入的 LongBench 子任务，下降的区间上界 \(\le 1.0\) 分；
- 每个纳入的 RULER 长度，下降的区间上界 \(\le 1.0\) 分；
- 上述各项点估计的宏平均下降 \(\le 1.0\)。

AIME 只报告点和区间，不进入这条逻辑。区间上界超过预算即不通过，即使点估计看起来很小。某项没有足够样本把区间做到窄于预算时，该项为 `underpowered`，分配不能标成通过。

### 16.2 三条主对照

正式论文的推断句只从这三条里选。

**C1，分布。** 在分布块上，位置桶对 \(S\) 的偏 \(R^2\)，以及仅 K 减仅 V 的配对 \(S\)。假设：桶的偏 \(R^2\) 不小于层的偏 \(R^2\) 的一半，且仅 K 的 \(S\) 更大。假设失败就按实测写，不另找一个显著的层。

**C2，预测增量。** 在 `D_test` 小面板上，T-Group 的 \(\rho(M2)-\rho(M0)\) 与 T-Retrieval 的同一差值。假设：T-Group 的差值区间在 0 的右侧，T-Retrieval 的差值区间包含 0 或小于 T-Group 的差值。两条都报告。T-Retrieval 没有增量时，必须同时给出同页配对的 \(\Delta S\) 区间；没有 \(\Delta S\)，就不把「预测不了」写成结论。

**C3，混合空间。** 在 `D_test` 上比较 `S0`、`S2`、`S3` 的任务预算可行性和 \(B_{\mathrm{DRAM}}\)。主句子是下面三者之一，由数据选择，不能并列声称：

1. `S3` 在三个模型上都以更少的平均字节满足第 16.1 节，且字节差的来源表显示组大小放宽贡献了其中的主要部分。
2. `S3` 的任务分与 `S2` 同级，但平均字节更低，字节差来自组大小而不是比特。
3. `S3` 相对 `S2` 没有字节或任务分上的收益。页关闭统计不进入后续课题的默认特征。`S4` 若仍然更好，收益记在离线参照名下。

「主要部分」指组大小变化所解释的字节差不少于总字节差的一半。这个比例在 P2 写死。

### 16.3 成文时用哪一条路径

P3 之后按实测填写，不在 P1 填写。

| 实测 | 论文主句 | 交给后续课题的默认 |
| --- | --- | --- |
| C2 的 T-Group 与 T-Retrieval 增量都成立，C3 取 1 或 2 | 页关闭统计同时改善了比特风险和组大小 | `F1`+`F2` 进入课题 W 的成本清单；课题三可以逐页选 \(b\) 和 \(g\) |
| 只有 T-Group 增量成立，T-Retrieval 的同页 \(\Delta S\) 区间离开 0 | 关闭时信息能决定组大小；中间页是否被检索不能由这些统计决定。位置和层头坐标负责比特底线 | 课题三的默认策略是：坐标定 \(b\)，`F1` 定 \(g\)。不设计逐页比特预测器 |
| `M0` 已经达到 `M3` 的预登记比例，C3 取 3 | 在这套覆盖里，页内统计没有超过坐标。若 C1 的分布本身稳定、2×2 和等字节对照有明确机制，论文写质量规律和预测上界；否则并入课题三，不单独成篇 | 课题 W 不实现额外统计电路 |

「`M0` 达到 `M3`」指 T-Group 和 T-Retrieval 上 \(\rho(M0) \ge 0.8\,\rho(M3)\)。0.8 与第 12.4 节的门相同，已在预登记里。

少量特征失败不写成负面论文。负面结论要同时有：覆盖范围（模型、任务、面板）、\(\Delta S\) 排除了「标签只是噪声」的解释、以及因此改动的设计（不把哪类统计放进写通路）。

## 17. 执行顺序

每一步的输出是下一步的输入。

1. **P0。** 黄金量化、打包、ILP 穷举核对、特征不读 oracle 的测试。
2. **数据清单。** 下载并钉修订。写划分。跑全精度守门。守门失败则停止。
3. **P1 计时与 E1。** 主模型小面板。得到秩相关的初步区间和单次 `closure_fork` 耗时。这一步决定分布块是否维持「全部头」。
4. **P1 的 E2 缩小版。** 起始页 2×2 只跑 8 条序列，确认四个条件在实现上真的不同（字节哈希两两不同，除非某两个条件在该输入上数值碰巧相同）。
5. **P2。** 冻结面板身份、\(\tau\)、位置策略的候选、预算、C1–C3。提交预登记。
6. **P3 分布。** E2 的正式表与 E1 的正式相关。两者都用预登记面板。
7. **P3 预测。** 先做同页配对的全精度纳入，再做量化分叉。并行拟合 `M0`–`M3`，只在 `D_test` 小面板上算一次增量。
8. **P3 分配。** 先 `S0` 和全精度，再 `S1`、`S2`，最后只跑一条 `S3` 和面板 `S4`。
9. **P4。** 按第 21 节导出交接文件。核对论文主句只使用 C1–C3 和筛选表。

第 6 步和第 8 步可以在不同 GPU 上并行。第 8 步不读取第 6 步的 `D_test` 结果来改分配；分配规则来自 `D_cal` 和 `D_sel`。

## 20. 实现时容易做歪的地方

这些条目是规程的一部分，检查表要逐条打勾。

1. 量化 cache 里 RoPE 之后的 K，并在日志记 `k_rope = post`。
2. 反量化写回 bfloat16 后再算 \(S\) 和 `local_attn`。
3. `closure_fork` 从页关闭的下一个 token 重算，不从问题句才开始替换。
4. 多页主条件从干净全精度页量化。需要「误差传递后再量化」时使用另一个 `intervention` 名字。
5. 页 0 永远进 `sink`，不因为距离近而改标成 `recent`。
6. 预测器训练脚本的特征白名单是 `f0`、`f1`、`f2`、`f3`。`oracle` 前缀读入即报错。
7. `D_test` 的划分文件在 P2 生成后只读。正式脚本检查运行时刻晚于预登记的 git commit。
8. 统一 4 比特失败时，保留这个点，标 `tested_fail`。不用一个更松的预算让它变成通过。
9. 组大小放宽节省的字节以 `byte_model.json` 为准。不另手算一个「平均 2.3 比特」。
10. 三个模型的通过状态分三行写。一个模型通过不代表另一个通过。
