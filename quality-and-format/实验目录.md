# 课题一实验目录

测量规程在 [课题一实验指导](课题一实验指导.md)。本文件只约定文件放在哪里、一次运行怎么命名、哪些内容进 git。规程与这里冲突时，先改其中一处再跑正式实验，不并行维护两套路径。

工作目录是 `quality-and-format/`。实验指导第 19 节和第 22 节的相对路径都从这里算。

## 树

```text
quality-and-format/
  configs/                  跨运行共享的清单，P2 前钉死
  quant/                    黄金量化与其单测
  pack/                     页布局、字节模型与其单测
  eval/                     三种干预、全精度守门、面板与全缓存评测
  features/                 F0–F3 提取，以及 M0–M3 的拟合
  allocate/                 面板 ILP 与穷举核对
  tools/                    划分与汇总
  data/splits/              只含 sample_id 的划分
  data/raw/                 下载的原文和权重，不提交
  runs/_template/           预登记模板
  runs/<run_id>/            一次运行的现场
  artifacts/                正式汇总，只由 tools/summarize.py 写出
  artifacts/pilot/          第 18 节的七张试跑表
  artifacts/handoff/        第 21 节交给其他课题的文件
```

课题说明、机制笔记和测量规程与代码放在同一目录：`README.md`、`敏感度分布与混合配置空间.md`、`课题一实验指导.md`。本文件只记目录约定。

## 运行名

`runs/` 下除 `_template` 以外，每个子目录是一次运行。运行名：

```text
{phase}-{protocol_version}-{scope}-{yyyymmdd}-{nn}
```

- `phase` 取 `p0`、`p1`、`p2`、`p3`、`p4`。其中 P0、P1、P3 各含两个子阶段。以 P0 为例，P0a 与 P0b 共用该次 `p0` 运行目录。
- `protocol_version` 取该次运行预登记中的规程标识。
- `scope` 取 `all`，或模型短名 `llama`、`qwen`、`r1qwen`。一次运行对应一个 `phase`。
- `nn` 是当天的两位序号，从 `01` 起。

例如，Llama 试跑可命名为 `p1-affine_min-llama-20261113-01`，全模型正式运行可命名为 `p3-affine_min-all-20261120-01`。

论文主表只引用一个 P3 运行。该运行名写在 `artifacts/SOURCE` 里，内容是运行名和产生它的 git 修订。每次运行使用独立目录。

## 一次运行里有什么

从 `runs/_template/` 复制出 `runs/<run_id>/`，再填写。

| 路径 | 内容 | 进 git |
| --- | --- | --- |
| `preregistration.yaml` | 第 15 节的键。P3 开始前已经提交 | 是 |
| `command.txt` | 实际命令、工作目录、开始时间 | 是 |
| `logs/*.jsonl` | 第 13 节的逐条记录 | 否 |
| `cache/` | 全精度 cache、打包页、中间张量 | 否 |
| `notes.md` | 这次运行的异常和剔除数量 | 是，若有 |

`logs/` 按干预分文件：`recon.jsonl`、`local_attn.jsonl`、`closure_fork.jsonl`、`closure_fork_joint.jsonl`、`tasks.jsonl`。任务分的样本级配对行在 `tasks.jsonl`，汇总平均只出现在 `artifacts/`。

## 正式汇总

`tools/summarize.py` 是 `artifacts/` 里正式文件的唯一写入者。手改过的表不能再被当成正式结果。文件名保持实验指导第 19 节和第 21 节的名字，不另起一套。

| 位置 | 何时写入 |
| --- | --- |
| `artifacts/pilot/` | P1 结束。文件名带 `pilot`，不进论文主表 |
| `artifacts/*.csv`、`artifacts/byte_model.json` | P3 汇总 |
| `artifacts/handoff/` | P4 |
| `artifacts/SOURCE` | 与正式汇总同一次提交 |

试跑表和正式表不放在同一个目录里。

## 提交

提交：`configs/` 里已经钉死修订的清单、`data/splits/`、每次被后续数字引用的 `preregistration.yaml` 和 `command.txt`、`artifacts/` 的正式结果、黄金量化单测哈希、以及实现这些结果的代码。

不提交：`data/raw/`、模型权重、`runs/*/logs/`、`runs/*/cache/`、`__pycache__/`。忽略规则在本目录的 `.gitignore`。

`data/splits/` 在 P2 提交之后视为只读。正式脚本若发现划分文件的 git 修订晚于预登记，应拒绝写出 `artifacts/pareto_tasks.csv`。
