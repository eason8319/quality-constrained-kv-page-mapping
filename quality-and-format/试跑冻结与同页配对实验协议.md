# 试跑冻结与同页配对实验协议

## 1. 正式端到端指标 \(S\)

单页量化相对全精度参照的**平均答案 token 负对数似然增量**，单位 **nats/token**。

对问题 \(q\)、目标页 \(p\) 和量化配置 \(c\)，标准答案为 \(y_{1:T}\)：

\[
S(p,c;q)=\frac{1}{T}\sum_{t=1}^{T}
\log\frac{P_{\mathrm{FP}}(y_t\mid q,y_{<t})}
         {P_{\mathrm{quant}(p,c)}(y_t\mid q,y_{<t})}.
\]

- 两条轨迹使用同一前缀、问题和正确答案历史。
- 量化轨迹从目标页关闭后的第一次读取起使用量化字节，扰动经后续缓存与网络层传播。
- \(S>0\) 表示量化降低了正确答案概率；**负值原样保留**。
- **关键答案步**沿用同一公式，单列为 \(S_{\mathrm{key}}\)：运行前标出首次区分候选答案的 token，只在该步取对数概率比。答案仅一 token 时 \(S=S_{\mathrm{key}}\)。
- 配对时先得各问自身的 \(S\)，再算 \(S_{\text{需要该页}}-S_{\text{无需该页}}\)。
- **自由生成答错率另报**，不并入 \(S\)。
- 局部 \(\Delta K/\Delta V\)、\(\Delta a/\Delta o\) 与端到端 \(S\) **分开报告**，不未经验证等同。

## 2. 主试跑冻结配置

| 项 | 冻结值 | 备注 |
|---|---|---|
| 模型 | Llama-3.1-8B-Instruct | 单模型先跑通 |
| 页长 \(L_p\) | 64 token | 备选复测 128 |
| 组大小 \(g\) | 64 | 备选复测 128 |
| 比特 \(b\) | 先 4 | 跑通后再分测 2 / 8 |
| 量化主体 | 非对称均匀；K 按通道、V 按 token | 项目共同基准 |
| 近期窗 | 128 token | **仅作位置分层坐标**；测量时刻见 §2.1 |
| 独立前缀数 | 32 | 正式样本量待试跑区间宽度后冻结 |
| 层/头抽样 | 早/中/晚各 2 层；每层 2 个 KV 头（固定种子）→ 12 个层头组合 | 全层全头留给正式 |
| 页位置分层 | 含首 token 页 · 近期已关闭页 · 较早历史页 | 首 token 页优先单列 |
| 关闭契约 | 关闭后不再升降档或重新分组；记录码字/尺度/零点/描述符哈希 | 两问复用同一份字节 |

质量参照为**全精度**，不以 8 bit 顶替。

### 2.1 近期分层的测量时刻

- 定义距离 \(d = t_{\mathrm{key}} - t_{\mathrm{page\_end}}\)，其中 \(t_{\mathrm{key}}\) 为**预测关键答案 token 时的查询位置**，\(t_{\mathrm{page\_end}}\) 为目标页末位置（该页最后一个 token 的位置下标）。
- 「近期已关闭页」：页在关键查询前已关闭，且 \(0 < d \le 128\)。边界 \(d=128\) 归入近期；\(d>128\) 归入较早历史页。
- 「含首 token 页」优先单列，即使其 \(d\) 落入近期窗也不并入近期桶。
- 每条轨迹元数据保存 \(t_{\mathrm{key}}\)、\(t_{\mathrm{page\_end}}\)、\(d\) 与位置桶标签。

### 2.2 轨迹规模（按冻结配置）

每个前缀 × 每个层头组合：12 条量化轨迹（扰动 A/B × 问甲/乙 × 仅K/仅V/KV）+ 每前缀 2 条可复用全精度轨迹（问甲/乙）。  
\(32\) 前缀 × \(12\) 层头 × \(12\) 量化 \(+ 32\times 2\) 全精度 \(= 4672\) 条 teacher-forcing 轨迹；自由生成与操纵检查另计。

## 3. 实验结构（两部分共用单页干预）

1. **同页配对**：同一页会不会仅因后续问题不同，在关键步变得敏感。
2. **代表性抽页**：这种情况有多常见；保护多少页能覆盖多少误差。

刻意检索题适合识别机制；其中检索频率由实验者设定，**不能**直接估计实际负载中高敏感页比例。32 前缀试跑用于打通流程并初估成本；分层 P95 须连同独立前缀数一起报告，高敏感页占比留到正式代表性抽页再判断。

### 3.1 同页配对交叉设计

前缀中放两条只能从上下文获得的事实，完整落在已关闭页 A、B。对每个选定 \((l,h,c)\)：

- 只扰动 A：测问甲与问乙；
- 只扰动 B：测问甲与问乙；
- 每种干预分别跑仅 K、仅 V、K/V；每问另跑全精度参照。

#### 缓存分叉顺序（可直接实现）

禁止「先跑完整段全精度前缀，到提问时才替换旧页」——那会漏掉旧页对中间缓存的影响。

**量化轨迹（对固定目标页 \(p\in\{A,B\}\) 与固定干预）：**

1. 全精度推进到目标页 \(p\) **即将关闭**（该页已写满、关闭打包完成）的状态；保存关闭时 KV 页字节（码字/尺度/零点/描述符）及哈希。
2. 在该关闭点**分出量化分支**：之后凡读取页 \(p\)，一律使用上述固定字节（仅 K / 仅 V / K/V 按干预选择字段）。
3. 用该固定字节继续跑完**剩余公共前缀**（A、B 均已关闭之后、问题之前的共享 token）。
4. 在公共前缀结束后**再分出问甲 / 问乙**；两问复用同一步骤 1–3 得到的页字节与中间缓存状态（问甲/问乙只是其后的问题与答案路径不同）。
5. 从关闭后**第一次读取**页 \(p\) 起即施加干预，包括步骤 3 的剩余公共前缀。

**全精度轨迹：** 独立跑完与量化轨迹相同的整段前缀与问题，不做页替换；按 `(prefix_id, question)` 缓存，供跨层头复用。

目标页关闭时只打包一次；问甲/问乙哈希必须一致。

#### 配对效应与 role

主配对效应：

\[
D=\tfrac12\big[(S_{A,\text{甲}}-S_{A,\text{乙}}) +(S_{B,\text{乙}}-S_{B,\text{甲}})\big].
\]

- 每条量化轨迹保存 `role ∈ {需要该页, 无需该页}`（相对**被扰动页**而言）。同一「问甲」对 A 为需要、对 B 为无需。
- **先在源前缀内**用四条 \(S\)（或 \(S_{\mathrm{key}}\)）算 \(D\)（及 A/B 各自差值），**再**按层头汇总跨前缀统计。
- 另保留「旧页被问到」方向；可报 \(I=S_{KV}-S_K-S_V\)。

每条轨迹三类读数：局部 \(\|\hat o-o\|_2\)（组内均值与最大值）、端到端 \(S\)/\(S_{\mathrm{key}}\)、自由生成翻转率。

操纵检查：替换 A 页事实后，全精度对问甲应变、对问乙应稳。报告通过率、全样本，以及全精度两问均对子集。

### 3.2 分布与集中度（正式阶段）

固定模型、\(L_p\)、分组与比特后：报告层间 P50/P95、同层同头格子内 P50/P95/P95−P50、按页非负损害 \(H_p\) 的累计份额曲线。若声称「保护前 5% 页挽回多少质量」，须在相同字节预算下实际重跑多页量化（高损害页 / 首部或近期 / 随机）；单页损害相加不能代替。

### 3.3 页关闭时预测验证（单独）

后续问题与未来注意力只用于构造离线标签。同一页关闭时给两分支的预测分数必须完全一致（泄漏检查）。

## 4. 32 前缀试跑数值门槛

分母均为「本批进入该检查的独立前缀数」（默认 32；被构造失败排除的前缀不计入分母，但须写入排除清单）。未达门槛不得扩到正式层头全覆盖或代表性抽页。

| 检查 | 阈值 | 分母 | 失败处理 |
|---|---|---|---|
| 同页两问字节哈希一致 | 100% | 本批前缀中含该目标页打包的次数 | 任一不一致 → 修 C 后重跑该前缀全簇；不得进入汇总 |
| 全精度两问均对 | ≥ 90% | 本批独立前缀 | 低于阈值 → 修模板/事实难度或剔除后补足到 32 个合格前缀再开量化批 |
| 操纵检查通过 | ≥ 95% | 本批做了操纵检查的独立前缀 | 失败前缀记录原因；通过率不达标则停扩批 |
| 零扰动回放 | 见下 | 每条抽检轨迹 | 超容差 → 视为分叉/对齐假效应，修完重跑 |

**零扰动回放（强制路径）：** 同一输入走**完整干预路径**（§3.1 分叉顺序），但把目标页字节换成关闭时保存的**原全精度页内容**（或等价「量化恒等」打包）。对每条抽检轨迹要求 \(|S| \le \tau_S\) 且 \(|S_{\mathrm{key}}| \le \tau_{\mathrm{key}}\)。试跑默认 \(\tau_S=\tau_{\mathrm{key}}=10^{-4}\) nats（若实现噪声系统性高于此，须先文档化实测噪声上界再改阈值，不得静默放宽）。

另须记录：单轨迹墙钟与显存；\(D\)、\(S\)、\(S_{\mathrm{key}}\) 的 P50/P95 及按源前缀整簇重采样的区间宽度；分层 P95 旁注独立前缀数。

建议顺序：先 **1 前缀 × 1 层头** 看清旧页第一次读取、两问哈希与关键步 \(\delta_t\)，再扩到 32 前缀。
