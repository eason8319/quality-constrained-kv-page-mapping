# 页级量化敏感度、写入统计的预测力与混合配置空间

本文档回答课题一的三个核心问题：

1. 页在不同层、KV 头、位置和上下文条件下的量化敏感度如何分布？
2. 写入时能够获得的统计量能否预测这种敏感度？
3. 这种差异是否提供了值得硬件利用的混合配置空间？

文中内容分三类。标为**推导**的公式只在当场写出的假设下成立。标为**文献**的数字来自所引论文，不是本课题的测量。标为**边界**的句子说明该证据不能直接当成页关闭映射的结论。共同约束仍以总研究规划为准：比特档为 2、4、8，量化主体为非对称均匀量化，K 按通道、V 按 token 是共同基准。

## 0. 从页内重建误差到任务损失

设第 $l$ 层、第 $h_{kv}$ 个 KV 头的缓存按固定页长 $L_p$ 分成页。页 $p$ 覆盖的位置集合为 $\mathcal{T}_p$，原始键、值矩阵为 $K_p,V_p$。在分组查询注意力（GQA）中，该 KV 头被一组查询头 $\mathcal{G}(h_{kv})$ 共享。

配置 $c$ 给出 K、V 的比特档和组大小。量化后再反量化，得到该页的重建误差

$$
\Delta K_p(c)=\hat K_p(c)-K_p,\qquad \Delta V_p(c)=\hat V_p(c)-V_p.
$$

后续解码步 $t$ 的查询为 $q_{t,h}$。只量化页 $p$、其余页保持参照精度时，扰动按下面三步传播。

**Logit 扰动。** 只出现在 $j\in\mathcal{T}_p$：

$$
\delta z_{t,h,j}=\frac{1}{\sqrt d}\sum_{m=1}^{d} q_{t,h,m}\,\Delta K_{p,(j,m)}.
$$

**注意力权重的一阶扰动。** 记 $a=\operatorname{softmax}(z)$。对列向量形式的 softmax，

$$
\Delta a_{t,h,i}\approx a_{t,h,i}\,\delta z_{t,h,i}-a_{t,h,i}\sum_{k}a_{t,h,k}\,\delta z_{t,h,k}.
$$

页外位置的 $\delta z$ 为零，求和只保留 $k\in\mathcal{T}_p$。因此一个页的 Key 误差会改变所有位置的权重，包括该页之外的位置。

**注意力输出的一阶分解。** 记 $o_{t,h}=\sum_j a_{t,h,j}v_j$，并略去 $\Delta a\,\Delta V$ 二阶交叉项：

$$
\Delta o_{t,h}^{(p)}(c)
\approx
\sum_{j\in\mathcal{T}_p} a_{t,h,j}\,\delta z_{t,h,j}\,(v_j-o_{t,h})
+
\sum_{j\in\mathcal{T}_p} a_{t,h,j}\,\Delta v_j.
$$

第一项是 Key 误差经过 softmax 雅可比后的输出扰动，第二项是 Value 误差按注意力权重做凸组合。任务损失若在全精度点展开，一阶项是 $\partial\mathcal{L}/\partial o$ 与 $\Delta o$ 的内积；二阶项由损失对相关激活的 Hessian 决定。本文件不把二阶项写成某个可直接计算的 Fisher 估计。

这三层量回答的问题不同：

- $\Delta K,\Delta V$ 是页内数值被改了多少。
- $\Delta a,\Delta o$ 是单步注意力被改了多少。单页、单层、且不把扰动送入后续层时，它是局部敏感度。
- $\Delta\mathcal{L}$ 或任务得分变化包含层间传播、自回归误差累积，以及多页同时量化的交互。

未做对照实验时，这三层量保持分开。

## 1. 敏感度如何沿层、头、位置和上下文分布

### 1.1 推导：四个因子相乘

单页对输出或损失的影响可以看成四个因子的乘积：页内重建误差的大小、该页在未来得到的注意力质量、softmax 在当前分布处的曲率，以及后续网络对输出扰动的放大。

**层。** 非对称均匀量化的步长由组内极差决定。高分辨率下，均匀量化的均方误差随极差的平方增长、随 $4^{b}$ 下降。不同层的投影和激活极差不同，所以同样比特下 $\Delta K,\Delta V$ 已经不同。浅层的局部注意力误差还要经过后面各层；深层输出更靠近语言模型头，输出方向的变化更直接改变下一个 token 的排序。测量到的“浅层局部峰值”和“深层梯度加权上升”可以同时存在，公式本身不要求敏感度随层号单调。

**头，以及 K 与 V 的不对称。** softmax 雅可比在位置 $i$ 的主系数是 $a_i(1-a_i)$。

- 注意力集中在一个主导位置且量化没有翻转这个优势时，其余位置的 $a_j(1-a_j)$ 很小，Key 噪声被压低。KVTuner 附录 A 把这一机制写成：若位置 $i$ 的 logit 优势在扰动后仍然成立，则该位置的权重仍接近 1。
- 多个位置的 logit 接近时，$a(1-a)$ 变大，很小的 $\delta z$ 就能改变峰值的相对大小。

Value 误差进入输出时是凸组合 $\sum_j a_j\Delta v_j$，其范数不超过各位置 Value 误差范数的加权最大；零均值、弱相关的 Value 噪声还会按 $\sum_j a_j^2$ 衰减。Key 误差先进入指数，再由上面的曲率放大。因此在同一套均匀量化下，K 通常比 V 更值得分配精度。这是机制上的倾向，仍要由目标模型和量化粒度上的测量确认。

GQA 使同一份 $\Delta K_p,\Delta V_p$ 进入多个查询头。只要组内有一个查询头处于多位置竞争、且与大误差通道对齐，这个 KV 页就会表现为高敏感。

**页位置。** 把页 $p$ 在后续解码中的累计注意力质量记为

$$
M_p=\sum_{t>\max\mathcal{T}_p}\sum_{j\in\mathcal{T}_p}a_{t,j}.
$$

$M_p$ 大，Value 项和 Key 项都被放大。按已有注意力现象，位置轴上应区分三类页，而不是假定敏感度随页号平滑变化：

- 序列起始页可能承载 attention sink。它的累计权重高，而且起始 token 的数值范围常偏离其余 token。若它和普通 token 共用量化组，还会拉偏整组的尺度。
- 刚关闭或仍在局部窗口内的页，会在接下来若干解码步中反复获得较高权重，误差立刻进入自回归链。
- 中间历史页的注意力通常稀疏。多数页的 $M_p$ 接近 0；少数被检索到的页在个别解码步上 $a_{t,j}$ 很高。

**上下文和任务。** 分组方向改变 $\Delta K$ 的协方差，敏感层的排序可以随之改变。普通语言建模里，单点扰动有机会被上下文冗余平均；长链条数学或代码推理里，一个关键 token 的翻转可以改变后续整条生成。后者对累计误差更敏感，不能用 WikiText 上的小困惑度差代替。

### 1.3 结论与边界

在已测模型和配置中，页敏感度沿四个轴都不均匀。

- 层：固定模型和量化方式后，局部误差或梯度加权分数的层间差异可以跨输入重复。浅层异常和深层升高可以并存。换量化轴后，敏感层可以改变。
- 头：稀疏、主导位置优势未被破坏的头，注意力权重更稳；多位置竞争的头更敏感。同样平均比特下，把更多精度给 K 的局部输出误差更小。Key 头内部的通道敏感度高度集中，GQA 组内的通道模式可以一致。
- 位置：起始 token 的高精度保护，以及推迟量化最近一段 KV，都能在所测设置下挽回很大一部分质量。中间页预期呈稀疏长尾，但现有实验还没有在同等预算下比较“保护首部、保护近期、保护随机页”。
- 任务：长思维链推理比困惑度更容易放大累计误差。

这些规律绑定模型、量化轴、组大小和敏感度定义。KVTuner 的局部注意力误差与 PM-KVQ 的梯度加权分数不是同一个排序。起始位置实验的收益同时包含“去掉该位置的误差”和“让量化器不再用该位置拟合尺度”。

## 2. 写入时的统计量能否预测敏感度

### 2.1 推导：页关闭时哪些因子已经存在

页 $p$ 写满时，决策只能使用当时还在的信息。把第 1 节的 Key 主项拆开，通道 $m$ 的贡献大致是

$$
\|\Delta K_{p,(:,m)}(c)\|
\times
\mathbb{E}_{t>\max\mathcal{T}_p}\!\left[
\left|q_{t,m}\sum_{j\in\mathcal{T}_p}a_{t,j}(1-a_{t,j})\,\tilde v_{t,j}\,\frac{\partial\mathcal{L}}{\partial o_t}\right|
\right].
$$

前半段由该页的数值和候选配置决定，页关闭时可以计算。后半段依赖未来查询、未来注意力和未来梯度。写入统计的预测力，取决于后半段里有多少能由静态坐标或关闭窗口内的伴随量代替。

**关闭时确定可知的量。**

- 层号、KV 头号、该页是不是序列起始页或当前局部窗口中的页。这些坐标不需要额外扫描。
- 量化本身就要用的组内最小值、最大值和尺度。均匀量化误差的无穷范数上界是步长的一半。
- 组内极差与组内典型幅度之比、超过固定阈值的元素个数。它们描述“一个离群值是否把整组步长撑大”。组大小放宽后会不会塌缩，主要由这个页内分布决定，不依赖未来查询。
- 若未满页仍保留足够精度，可以在关闭时直接计算各候选 $(b,g)$ 的重建误差。这需要额外减法、归约，或对多个组大小再扫描一次。

**关闭窗口内已经产生、但不是 KV 自身的量。**

页内 token 对应的查询，在这些 token 参与注意力时已经算过。MixKVQ 把通道显著性写成

$$
\mathcal{I}_d=\frac{1}{L_q}\sum_i |Q_{i,d}|,\qquad
\mathcal{S}_d=\frac{\max(k_d)-\min(k_d)}{2^B-1},\qquad
\mathcal{A}_d=\mathcal{I}_d\mathcal{S}_d.
$$

这里用 $\mathbb{E}|Q_{i,d}\epsilon_{j,d}|\approx\mathbb{E}|Q_{i,d}|\,\mathbb{E}|\epsilon_{j,d}|$，并用尺度代替误差幅度。若未来查询的通道活跃度和关闭窗口相近，这个乘积能比单独的 $\mathcal{S}_d$ 更接近 logit 误差。活跃度是否平稳，取决于查询投影和后续 token 的分布，不能事先当成对所有任务成立。

**关闭时看不到的部分。**

一个中间页会不会在很后面的解码步被新查询检索，取决于尚未生成的内容。页内极差、离群计数和当前窗口的查询幅值都没有包含这个未来事件。层、头上的离线先验可以提高该头的保底精度，但不能在页关闭时点名“哪一页是未来的针”。

只看 Key 尺度还会产生另一种错误：尺度大而对应查询通道几乎不活跃的通道，对 $qk^\top$ 贡献小；尺度中等而查询通道幅值大的通道，贡献可以更大。

### 2.2 文献

**Key 尺度与查询幅值相关性弱。** MixKVQ §4.1 和图 3 在 Qwen2.5-14B-Instruct 第 0 层报告，查询通道平均绝对幅值与 Key 尺度的皮尔逊相关系数为 0.16。Head 0 中 80% 的 Key 尺度落在 $[2.80,4.46]$。尺度单独使用时，通道之间挤在一起。

**乘上关闭窗口内的查询幅值后，推理分数提高。** MixKVQ 附录表 6 在 AIME 2024–2025 上比较 $\mathcal{A}_d=\mathcal{S}_d$ 与 $\mathcal{A}_d=\mathcal{I}_d\mathcal{S}_d$：

| 模型 | 只用尺度 | 尺度乘查询幅值 |
| --- | ---: | ---: |
| R1-Qwen-14B | 53.33 | 60.00 |
| R1-Llama-8B | 33.33 | 40.00 |

这是任务准确率，不是敏感度排序的相关系数。它说明在该实验的通道选择里，查询项改变了最终精度分配的效果。

**边界。** MixKVQ 每 $R$ 个 token 用当前窗口的查询更新 $\mathcal{I}_d$。对“量化这一窗时，窗内查询已经存在”这一说法，它是直接证据。它没有证明：页关闭并提交之后，还可以用更后面的查询改写该页位宽。若实现会重写已经提交的页，则超出本课题“关闭后配置固定”的契约。

**静态坐标已经能指导粗粒度分配。** KVTuner 用离线测得的层间局部误差做精度对搜索，在线阶段直接加载，不再逐 token 决策。PM-KVQ 用校准集上的梯度加权分数做层间整数规划。二者都说明层这个坐标携带稳定信息；二者的分数定义不同，排序不能互换。

**通道平均绝对幅值可以当作在线代理。** Kitty 在分析实验里测量逐通道注意力 MSE，在线选择高精度通道时改用 Key 通道平均绝对幅值，以降低开销。这支持“幅值统计与通道敏感度有关”，同时说明在线电路用的代理和分析时的 MSE 不是同一个量。

### 2.3 结论与边界

预测力按信息来源分开，而不是对“统计量有没有用”给一个总的是否。

- 层、头、起始页和近期窗口这些坐标，已经解释跨页敏感度的主要结构。新增统计量要和只使用这些坐标的规则比较，确认增量。
- 组内极差、尺度、峰均比和离群计数，直接决定均匀量化步长以及放宽组大小后的额外失真。它们预测的是重建误差和组大小是否安全，不是未来注意力质量。
- 只使用 KV 自身尺度去给通道或页排敏感度，区分度有限。MixKVQ 给出的相关性是 0.16，且尺度分布集中。
- 页写满时已经算过的查询通道幅值，可以和尺度相乘，改进“哪些通道真正进入 logit”。这个量属于关闭前已经产生的伴随信息。它不是未来查询，也不应在页提交后继续更新该页配置。
- 中间页未来是否被远距离检索，超出页内统计的信息范围。

成本上分开记录：

- 坐标和当前组的最小、最大、尺度，量化通路本身就会产生。
- 绝对值和、平方和、固定阈值计数、窗口内 $|Q|$ 的累加，可以随 token 到达更新。
- 多个候选组大小上的真实重建误差、精确分位数，需要保留高精度数据或额外扫描。软件里算得出，不等于写通路里成本低。

## 3. 差异是否构成值得硬件利用的混合配置空间

### 3.1 推导：失真比与摊销

设页 $p$ 的敏感度权重为 $w_p>0$。在高分辨率、误差近似均匀且各页失真可加的假设下，把位宽为 $b_p$ 时的页失真写成 $w_p\,4^{-b_p}$。在平均位宽 $\frac1N\sum_p b_p=\bar b$、位宽连续的条件下，最小化总失真得到

$$
b_p^*=\bar b+\frac{1}{2}\log_2\frac{w_p}{\operatorname{GM}(w)}.
$$

其中 $\operatorname{GM}(w)=(\prod_p w_p)^{1/N}$。代入后，每一页的加权失真都等于 $4^{-\bar b}\operatorname{GM}(w)$。统一位宽 $\bar b$ 的总失真与该混合分配的总失真之比为

$$
\frac{\mathcal{D}_{\mathrm{unif}}}{\mathcal{D}_{\mathrm{mix}}}=\frac{\operatorname{AM}(w)}{\operatorname{GM}(w)}\ge 1.
$$

$\operatorname{AM}$ 是算术平均。权重越分散，这个比越大。第 1 节的文献表明 $w_p$ 沿层、头和位置可以差很多，所以**在上述失真模型内**，混合位宽相对统一位宽有确定的数学空间。

这个比不是任务准确率的提升倍数。任务得分对误差的响应是非线性的：统一 2 bit 可以因为少数页破坏整条推理，统一 4 bit 或 8 bit 则让大量低权重页支付同样的存储和访存。水填充公式只说明“权重分散时，最优连续分配会离开统一位宽”；硬件上的候选仍是 $\{2,4,8\}$ 和离散组大小。

页 $p$ 关闭后还要被读取 $N_{\mathrm{read}}(p)$ 次。一次关闭的统计、决策、量化和打包成本记为 $E_{\mathrm{write}}(p)$，一次读取的数据、元数据、反量化或低比特累加，以及模式切换成本记为 $E_{\mathrm{read}}$。相对满足同一质量预算的最佳统一配置，混合配置有净收益的条件是：各页读取阶段省下的能量，大于关闭阶段多出来的能量，加上描述符和切换在全部读取中的累计成本。

早关闭的页会在后续大量解码步中被重复读取，$N_{\mathrm{read}}$ 可以达到后续 token 数的量级。刚关闭的近期页剩余读取次数少，写入开销更难摊销。因此“长上下文有利于摊销”适用于早、中期页，不自动适用于序列尾部的页。

组大小进入同一笔账。若每组保存一个 16 bit 尺度和一个 16 bit 零点，组内有 $g$ 个 $b$ bit 元素，则元数据字节与数据字节之比为 $32/(g b)$。$b=2$ 时该比为 $16/g$：$g=64$ 时为 25%，$g=128$ 时为 12.5%。这是该表示假设下的计算，不是某篇论文的测量。它说明 2 bit 页上，尺度和零点不再是可以忽略的尾数；低敏感且组内没有极端离群值的页，放宽组大小会同时减少元数据。放宽之后，尺度沿归约维变化减少，才可能把乘加留在低比特域、把尺度移出内层循环。组内极差被离群值主导时，放宽组大小会直接增大 $\Delta K,\Delta V$，质量约束会禁止这种组合。

### 3.2 文献

下面的系统结果都是原论文在 GPU 软件栈上的测量。它们证明混合精度有质量—容量空间。它们没有测量本课题的页描述符、模式 A/B 或专用读写通路。

**层间混合精度可以低于统一 4 bit，同时保持数学推理分数。** [KVTuner](https://arxiv.org/html/2502.04420v5) 表 5 在 GSM8K few-shot 与多轮设置上的平均准确率：

| 模型与量化 | 设置 | 平均准确率 |
| --- | --- | ---: |
| Llama-3.1-8B-Instruct | BF16 | 0.8038 |
| 同上，KIVI | KIVI-4 | 0.8011 |
| 同上，KIVI | KVTuner-C3.25 | 0.7925 |
| 同上，KIVI | KIVI-2 | 0.6327 |
| Qwen2.5-7B-Instruct | BF16 | 0.7755 |
| 同上，per-token | KV4 | 0.0078 |
| 同上，per-token | KVTuner-C4.00 | 0.7559 |
| 同上，KIVI | KIVI-4 | 0.1043 |
| 同上，KIVI | KVTuner-C5.96 | 0.7724 |
| 同上，KIVI | KVTuner-C3.92 | 0.6160 |

Llama-3.1-8B 的 KIVI 混合配置在等价 3.25 bit 时平均分为 0.7925，低于 BF16 的 0.8038，也略低于 KIVI-4 的 0.8011，同时明显高于 KIVI-2 的 0.6327。Qwen2.5-7B 对低比特更敏感：统一 KV4 在 per-token 模式下平均分落到 0.0078，KIVI-4 落到 0.1043；KVTuner 的 4.00 bit per-token 配置为 0.7559，KIVI 路径要到 5.96 bit 才回到 0.7724。原文摘要中的“多数模型上 4 bit 甚至 3.25 bit 几乎无损”需要和表 5 的模型、量化方式一起读，不能写成所有受测模型在 3.25 bit 都接近 BF16。

吞吐方面，KVTuner §6.4 报告：层间精度对完全离线搜索，在线不再做精度选择。Llama-3.1-8B-Instruct 上，相对 KIVI-KV8，KVTuner-C3.25 的解码吞吐提高 16.79%–21.25%。21.25% 对应输入长度 64、生成长度 128 的一个批次设置，比较对象是 KIVI 的 8 bit，不是统一 4 bit。

**长思维链上，层间 2/4 bit 分配优于在同一低比特上均匀量化。** [PM-KVQ](https://arxiv.org/html/2505.18610v2) §4.2 的原文概括是：

- DeepSeek-R1-Distill-Qwen-7B 在最终位宽为 2 bit、batch size 为 40 时，PM-KVQ 相对 KIVI 最多高 8 个百分点；RotateKV 和 MiKV 在该 2 bit 设置下不能生成有效回答。
- 把 batch size 降到 32 后，每个样本的显存预算变大，仍不够所有 block 使用统一 4 bit。PM-KVQ 用 block 间分配多得到至多 0.84 个百分点。
- DeepSeek-R1-Distill-Qwen-14B 上，KIVI 在 CMIMC-2024 的 pass@1 下降 21.87 个百分点；PM-KVQ 在 batch size 16 和 12 下分别下降 1.87 和 2.91 个百分点。
- DeepSeek-R1-Distill-LLaMA-70B 的 AIME-2024：16 bit 为 69.14%，KIVI 2 bit 为 51.88%，PM-KVQ 2 bit 为 64.79%，比 KIVI 高 12.91 个百分点。

PM-KVQ 的 2/4 混合与 KIVI 的统一 2 bit 往往对应不同 batch size 或不同的显存占用过程。引用时保留这个条件。它支持“敏感层拿更高比特可以避免统一低比特的崩溃”，不能直接换算成同一 DRAM 流量下的加速比。

**通道混合精度把平均位宽压到 2.3–2.7 bit。** MixKVQ 表 3，四项推理任务的平均准确率：

| 模型 | BF16 | 统一 4 bit（RotateKV） | 统一 2 bit（KIVI） | MixKVQ |
| --- | ---: | ---: | ---: | ---: |
| R1-Distill-Llama-8B | 53.77 | 49.45 | 43.11 | C2.7：51.89 |
| R1-Distill-Qwen-14B | 64.73 | 61.73 | 55.41 | C2.3：63.10 |
| R1-Distill-Qwen-32B | 67.84 | 64.51 | 58.89 | C2.3：66.04 |

Qwen-32B 上，RotateKV 比 BF16 低 3.33 个百分点，KIVI-KV2 低 8.95 个百分点，MixKVQ-C2.3 为 66.04，比 RotateKV 的 64.51 高 1.53 个百分点。2.3 与 4 的比是 $2.3/4=0.575$，即论文所报平均位宽比 4 bit 少 42.5%。该百分比只比较论文报告的平均位宽，没有扣除尺度、零点、残差缓冲和 BF16 通道在真实访存里的额外字节。

MixKVQ 附录表 7 在 R1-Qwen-7B 上给出：通道选择占每层时间的 2.17%、调用次数的 3.13%；同一段文字把超过 79% 的 KV 容量节省对应到从 16 bit 压到 3.4 bit，即 $(16-3.4)/16=78.75\%$。图 5 的 $2.25\times$ 批大小和 $2.63\times$–$2.81\times$ 吞吐，是 Llama-2-13B-chat 上 MixKVQ 相对 FP16、在显存打满时的比较，残差长度为 32 或 128。这三项来自不同模型或不同位宽，不能合成“2.17% 开销换来 2.7 倍吞吐”。

**页式布局已经承载过通道级混合精度。** [Kitty](https://arxiv.org/html/2511.18643v1) 摘要报告：动态保留少数高敏感 Key 通道的更高精度，其余通道压到 2 bit，在七个任务、Qwen3 与 LLaMA3 上以接近 2 bit 的 KV 容量（相对 16 bit 近 $8\times$）保持很小的精度损失；同一显存预算下批大小最多约 $8\times$，吞吐约 $2.1\times$–$4.1\times$。其实现把混合精度 Key 页拆成两份对齐的 2 bit 张量，避免按通道散读。这是 GPU 页布局上的结果，精度提升的是少量通道而不是整页切换模式 A/B。

**低比特注意力的硬件含义在 GPU 上已经出现，但机制不同。** [QServe](https://arxiv.org/abs/2405.04532) §3.1 把解码注意力看成计算强度为每元素 1 次乘加的 GEMV：流量由 KV 读取主导，KV4 相对 KV8 把这部分的峰值性能提高到 2 倍。同一论文指出，当时的 INT4 方法在 GPU 上对权重或部分和做反量化，运行时开销可达 20%–90%。这是 GPU 的 CUDA core 与 tensor core 分工，不是本课题模式 A/B 的面积或能量结果。它说明两件事：KV 位宽会改变内存受限注意力的流量；反量化若放进内层循环，节省的流量可以被计算开销吃掉。

### 3.3 结论与边界

混合配置有值得继续做硬件设计的空间，空间分成三层，证据强度不同。

1. **比特档。** 文献已经在多个模型上表明：统一 2 bit 会在部分推理模型上明显掉点，统一 4 bit 或 8 bit 又给低敏感层支付同样的容量。层间或通道间混合可以把平均位宽放到约 2.3–4 bit 的区间，并在部分模型上接近全精度或优于同任务上的统一 4 bit。Qwen2.5-7B 在 KVTuner 表 5 中需要高于 4 bit 的 KIVI 混合配置才回到 BF16 附近，所以“压到 3 bit 附近仍无损”不是跨模型结论。
2. **组大小。** 2 bit 下尺度和零点的字节占比随 $16/g$ 上升。页内离群统计能够决定哪些页可以放宽组大小。这一层目前是推导和表示计算，还没有本课题的质量实验。
3. **读通路模式。** 现有 GPU 方法把混合精度主要用作存储格式，计算前仍反量化到浮点。专用通路还有一个额外变量：组大小足够规则时，低敏感页可以在低比特域累加后再乘尺度。这个变量是否有净能量收益，要等读通路的代价模型和课题一的质量验证，不能从 QServe 的 GPU 2 倍峰值直接搬过来。

页级、关闭后固定的配置，和 KVQuant 那种逐元素离群索引不同。前者保持对齐的页读取，用描述符选择比特、组大小和模式；后者用稀疏索引表达少量元素。Kitty 和 MixKVQ 的通道级精度说明敏感度可以细到通道。若硬件按页或按固定组切换，通道级收益是页内统计要去逼近的上界，不是当前页格式已经实现的粒度。

离线使用未来注意力或全程序梯度得到的分配，只是潜力参照。页关闭策略能用的，是第 2 节里关闭时已经存在的坐标和统计。比较顺序应是：统一配置，然后只用层、头和特殊位置的混合，然后再加入页内统计。后一步没有增量时，粗粒度先验仍然可以交给后续课题；不能把离线参照的收益写成在线页关闭已经达到的收益。
