## A. 环境与参照

- [ ] 固定模型权重与分词器版本（Llama-3.1-8B-Instruct），记录 commit / 权重哈希
- [ ] 全精度 dtype、注意力实现、生成与 teacher-forcing 路径一致且可复现（固定种子）
- [ ] 量化实现：非对称均匀；K 按通道、V 按 token；\(b=4\)，\(g=64\)
- [ ] 页关闭打包输出：码字、尺度、零点、描述符；可计算内容哈希
- [ ] 关闭后禁止升降档 / 重新分组；干预从关闭后**第一次读取**起生效
- [ ] 零扰动回放：走完整干预分叉路径，目标页换回原值；\(|S|,|S_{\mathrm{key}}|\le 10^{-4}\) nats（或文档化后的噪声上界）

## B. 前缀与模板构造

- [ ] 随机生成只能从上下文获得的两条事实，完整落入已关闭页 A、B（例：校验词）
- [ ] 事实落在页内且不跨页；首部位置类时事实在首 token **之后**
- [ ] 跨前缀：交换档案标签与物理页位置；随机分配答案词
- [ ] 同模板两问：「档案甲…？」「档案乙…？」；分词后问题长度、答案长度对齐
- [ ] 运行前标注关键 token（首次区分两候选答案的位置）；写入元数据
- [ ] 保存 \(t_{\mathrm{key}}\)、各目标页 \(t_{\mathrm{page\_end}}\)、\(d=t_{\mathrm{key}}-t_{\mathrm{page\_end}}\)；按协议 §2.1 打位置桶（首 token 页优先单列；\(0<d\le 128\) 为近期，\(d=128\) 归近期）
- [ ] 每个前缀能覆盖拟定位置意图；生成 32 个独立前缀 ID 并保留构造种子

## C. 页量化与字节复用

- [ ] 目标页关闭时**只打包一次**；存 `(data, scale, zero, desc, hash)`
- [ ] 问甲 / 问乙复用同一份目标页字节（哈希必须相同）
- [ ] 仅 K、仅 V、K/V：K/V 联合复用两单项实验的 K、V 字节
- [ ] 非目标页保持全精度（或实验规定的参照精度）
- [ ] 后续新产生的缓存按**实际轨迹**计算，不回写为干预前状态

## D. 轨迹调度与缓存分叉

试跑层头：早/中/晚各 2 层 × 每层 2 KV 头（12 组合）；\(c\) 先取 \(b=4,g=64\)。

### D0. 分叉顺序（强制）

对固定目标页 \(p\) 与干预：

1. 全精度推进到 \(p\) 关闭并打包；
2. **在关闭点**分出量化分支，之后读 \(p\) 用固定字节；
3. 用固定字节跑完**剩余公共前缀**；
4. 公共前缀结束后再分出问甲 / 问乙；
5. 全精度轨迹独立跑完整段前缀+问题，按 `(prefix_id, question)` 复用。

- [ ] 调度器实现上述顺序；单元测试覆盖「旧页在剩余公共前缀中被读取」的路径
- [ ] 禁止提问时才换页的实现

### D1. 轨迹表

每个前缀 × 每个层头：12 条量化 +（每前缀）2 条全精度 ≈ 全试跑 4672 条 teacher-forcing（自由生成与操纵另计）。

| # | 扰动页 | 问题 | role（相对扰动页） | 干预 |

| 1–2 | A | 甲 / 乙 | 需要 / 无需 | 仅 K |

- [ ] 轨迹键含：`(prefix_id, l, h, c, page, question, role, intervene)`
- [ ] 失败轨迹记录原因，不静默丢弃

## E. 三类读数

### E1. 局部输出误差

- [ ] 固定该分支全精度轨迹的 \(q_t\) 与其余 KV，只替换目标页，同层重算注意力输出
- [ ] 对共享该 KV 头的每个查询头记 \(\|\hat o-o\|_2\) 与相对误差
- [ ] 报告组内**均值**与**最大值**

### E2. 端到端 \(S\) / \(S_{\mathrm{key}}\)

- [ ] Teacher-forcing 正确答案前缀；逐步 \(\delta_t=\log P_{\mathrm{FP}}-\log P_{\mathrm{quant}}\)
- [ ] \(S=\mathrm{mean}_t\delta_t\)；\(S_{\mathrm{key}}\) 仅关键步；负值保留

### E3. 自由生成

- [ ] 同批前缀补跑自由生成（解码参数固定并记录）
- [ ] 全精度对→量化错；反向翻转率；**不并入** \(S\)

## F. 效应与检查

- [ ] **先在源前缀内**算 \(D\)（及 \(D_{\mathrm{key}}\)、A/B 各自差值），再按层头跨前缀汇总
- [ ] 汇总保留 `role` 与「旧页被问到」方向；可选 \(I=S_{KV}-S_K-S_V\)
- [ ] 操纵检查：改 A 事实 → 全精度问甲变、问乙不变；按 §4 门槛判定
- [ ] 全样本与「全精度两问均对」子集同时报告

## G. 试跑出门条件（数值门槛）

| 检查 | 通过条件 | 失败处理 |
|---|---|---|
| 哈希一致 | 100% | 修 C，重跑该前缀全簇 |
| 全精度两问均对 | ≥ 90% 前缀 | 修模板或补足 32 个合格前缀 |
| 操纵检查 | ≥ 95% 前缀 | 停扩批，修构造/检索 |
| 零扰动 | 完整干预路径 + 原页字节；\(|S|,|S_{\mathrm{key}}|\le 10^{-4}\) nats | 修分叉/对齐后重跑 |
| 成本与区间 | 记录墙钟/显存；报 \(D,S,S_{\mathrm{key}}\) 的 P50/P95 与整簇重采样宽度；分层 P95 旁注独立前缀数 | 据此才冻正式 \(N\) |

- \(b\in\{2,8\}\) 与 \(L_p=128\)/\(g=128\) 复测（主配置出门后再开）
