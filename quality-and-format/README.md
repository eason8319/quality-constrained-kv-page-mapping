# Quality Characterization and Storage Formats for Low-Bit KV Cache Pages

课题一：低比特 KV 页的质量特征与存储格式

[返回总研究规划](../质量约束下低比特KV页联合映射-论文课题.md)

本文件展开本课题的研究内容；共同约束与跨课题接口以总研究规划为准。调整本课题范围时，应同步更新总文档对应章节。

## 1. 核心问题

页在不同层、KV 头、位置和上下文条件下的量化敏感度如何分布？写入时能够获得的统计量能否预测这种敏感度？这种差异是否提供了值得硬件利用的混合配置空间？

存储格式、元数据模型和静态打包电路作为承载这些配置的支撑内容。

## 2. 研究内容

1. **敏感度定义与测量。** 规定某页、某配置相对参照造成的扰动。区分 KV 重建误差、注意力或输出扰动、任务质量变化，不未经验证就将它们等同。研究单页扰动，并检查多页同时量化时的交互与累计影响。
2. **敏感度分布。** 分析层、头、页位置及上下文条件下的差异和稳定性。报告适用范围、例外与不确定性，不将某个模型的规律直接推广到所有模型。
3. **可获得统计量的预测力。** 探索范围、离群计数和误差估计等候选量。与仅使用层、头、页位置的简单基线比较，确认额外统计的增益。预测特征只能来自决策时已经存在的信息。
4. **理想离线混合分配。** 在固定的候选空间和明确的资源预算下，用离线敏感度构造分配参照，检验混合配置的收益空间。可利用未来信息的离线参照必须明确标注，不能作为可在线实现的策略。
5. **配置筛选。** 将配置标记为“统一使用通过”“指定混合协议下通过”“在已测协议下未通过”；尚未验证的单列为待验证。记录测试覆盖、混合比例和选页规则，不把有限测试的失败解释为普遍不可用。
6. **格式支撑。** 定义数据、尺度、零点及描述符布局，建立包含对齐浪费的字节与访存模型；实现参考打包与解包，以保证质量实验使用的配置可以表达。

候选统计量先在软件中验证。若某项统计需要保留原始高精度数据、多份候选表示或额外扫描，必须记录这一前提，供 W 核算成本。软件可以计算的量不自动视为低成本硬件统计。

## 3. 贡献边界

本课题负责“存在什么可利用规律、写入信息能预测多少、理想分配有多大潜力”。不负责最终的硬件成本感知映射，不设计可重构读通路，不以在线重编码电路作为核心贡献。

离线分配使用简单规则或可核验求解，目的是测量潜力。启发式搜索得到的解称为离线参照；只有穷举或具有可验证最优性依据的结果，才称为所定义问题的离线最优。

## 4. 成文判定与退路

独立成文需要形成可复现、有解释力的质量规律或预测边界，并说明其如何改变配置或系统设计。仅展示敏感度热图、字段字节数或一次预测效果，不足以满足这一条件。

如果写入统计预测力弱，需要证明这一结果在明确覆盖范围内稳定成立，排除测量噪声、标签定义和实验设计造成的假象，并给出失效机制或设计启示。少量统计量预测失败不自动构成可发表的负面结论。

若层或头层面的规律更稳定，可向课题三提供粗粒度先验。该退路维持研究主线，但课题三仍需重新检验相对已有层级混合精度方法的贡献。若本课题只有支撑性结果，则作为共同基础或并入课题三，不强行独立切篇。

## 5. 交付物

敏感度定义与测试协议、分布与预测结果、配置及其验证状态、离线分配参照、参数化页格式、元数据模型，以及候选统计量的数据依赖。

## 并行开展与交接

可与课题二、W 并行启动，先固定敏感度测量协议与候选配置范围，无需等待最终 RTL。

- 向课题二提供质量验证后的配置与页格式，并接收新尺度组织的补充验证请求。
- 向课题 W 提供候选统计量及其数据依赖；统计电路定型等待预测价值确认，W 的核心研究不等待。
- 向课题三提供质量规律、预测结果、配置状态与离线分配参照，不替代成本感知的最终决策。

## 共同约束与接口

- 比特档为 2、4、8；以 K 按通道、V 按 token 的非对称均匀量化为共同基准，不以训练、微调或新量化公式为贡献。
- 页长在一次实验或实现内固定。配置必须能被页格式表达、由保留数据生成，并由实际通路执行。
- 使用共同的全精度质量参照、校准与测试划分、比特精确模型、硬件预算及完整成本口径。
- 初期保持参数化；最终实现与正式评估前共同冻结尺度语义、页生命周期、描述符、配置集合和成本接口。
- 模型、任务、质量预算和具体硬件参数尚待共同确定；本文描述研究目标，不表示已取得实验结果。
